# Wi-Fi CSI 人数识别 · Huawei TechArena 2026

这个项目研究如何通过 Wi-Fi 信号判断房间里有多少人。输入是连续 600 帧信道状态信息（CSI）和帧间时间间隔，模型需要给出 0—4 人的预测，最后以 ONNX 文件提交评测。

## 问题与难点

比赛提供了 48 条有标签记录，我们将它们切成 960 个窗口用于训练和验证。数据来自少量房间，人数分布也不均衡：2—4 人的样本只出现在两个房间里。

难点在于，信号不仅受人数影响，也受房间布局、设备位置和人的活动影响。模型很容易记住房间特征，却不能在新的采集记录上准确判断人数。

## 做了什么

我们先训练了一个四分支模型，分别提取静态幅度、动态幅度、天线间相位关系和时间特征，再融合这些信息进行分类。

围绕这个模型，团队尝试了事件与注意力结构、模型扩容、多随机种子训练、重叠滑窗、外部数据、蒸馏和模型融合。验证时按完整记录或房间划分，避免把同一段采集的数据同时放进训练集和验证集。

后期的主要提升来自原模型的推理处理：调整类别偏置，将时间反转和接收天线排列作为不同视角进行融合，并保留部分原始判断，避免平均后反而改错。

## 结果

|阶段|公开平台准确率|
|---|---:|
|原四分支模型|37%|
|事件、注意力结构及其融合|38%—40%|
|原模型加入类别偏置|44%|
|加入时间反转与天线排列融合|47%|
|进一步调整融合与保护规则|**54%**|

最终选择的是 **G′ 版本**，文件放在根目录：[model.onnx](model.onnx)，约 83.68 MB。团队记录的最高公开成绩为 **54%**，没有达到最初设定的 60% 目标；私有测试结果尚未记录。

这次项目最直接的体会是：模型更大、窗口更多，并不一定更好。后续不少方案提高了本地成绩，却没有提高平台成绩。相比不断增加结构，数据覆盖、验证方式和输出校准同样重要。

## 仓库内容

- `src/`：数据预处理、模型、训练与导出代码。
- `experiments/`：各轮实验代码和结果。
- `tools/`：模型检查与分析工具。
- `docs/`：实验总结和方法说明。
- `models/`：模型信息与平台成绩记录。
- `manifests/`：训练窗口清单。

原始数据和训练缓存未上传，部分实验脚本需要本地数据路径。原训练记录见[复现说明](handoff/run037_20261025/README.md)，更多过程见[项目总结](docs/SUMMARY.md)。

## 本地检查

```bash
pip install numpy onnx onnxruntime
python src/check_model.py model.onnx
```

没有样例文件时，脚本使用全零输入检查接口。最终文件的哈希见[模型记录](models/final_submission.json)。本机最后一次样例计时约 0.93 秒，高于题目的 0.7 秒限制，具体检查结果保存在[这里](docs/FINAL_VALIDATION_20261113.json)。
