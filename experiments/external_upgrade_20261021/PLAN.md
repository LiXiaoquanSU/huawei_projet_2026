# 外部数据升级：训练前登记

保留原宽度spectral/physical四路结构，增加小型按真实链路/频点共享权重的时间CNN，将链路集合的均值/标准差/最大值聚合后残差接入256维融合表示。新路线不依赖固定天线数、频率位置，不把幅度调制称为校准的多普勒。

官方输入仍为600×1×3×1024×2；新增路线从现有静态幅度特征的3×32×4频点组均值取得96条150点序列，推理与训练缓存完全相同。外部只用真实链路和频点，按3秒低通重采样到150点，独立全窗归一化。时间CNN先逐序列归一化，再使用相对变化强度，弱化静态房间/硬件尺度。

实现说明：上述新低通重采样应用于RadioPoints/SHARP；Brescia沿用已审计v2的150点插值缓存，再将128频组聚合为32组，未重做原始插值前的抗混叠。其高频细节不可视为真实50Hz观测；三种来源均不用于物理速度标定。所有开发/全量拟合使用同一固定缓存。

四个变体：source_control（官方源数据预训练/辅助，同预算）；external_counts（RadioPoints+Brescia人数）；external_multitask（再加SHARP活动/存在）；conditional_multitask（再加官方同人数跨房间原型对比）。原0.37结构既有开发结果作为历史参照，不能替代本轮相同新增结构/采样的source_control。

预训练固定4轮×32更新、batch32、AdamW 1e-3、wd.01、clip3。外部全部RadioPoints15记录；Brescia仅原external_train518窗，日期留出303窗不训练；SHARP13记录485窗，空房/坐姿/步行/跑步四类。SHARP用活动CE+.2存在BCE，不给官方数据编造活动标签。每个外部更新按类别—房间/会话—记录平衡抽样。source_control仅使用本折官方源记录，匹配128更新。

官方微调固定5轮、batch32、AdamW4e-4、wd.01、clip3，沿用原任务损失，+.1官方共享路线人数CE，+.1辅助源批次损失；conditional版本另加.05类条件跨房间原型损失，温度.2。每轮先随机覆盖每条源记录一窗，再按类别—已观察房间—记录平衡补到原窗口总数，随后打乱。未知房间不进入开发训练，仅最终全量；最终全部48条有标签记录均使用。此轮不引入U伪标签或U预训练，以隔离新外部数据效果。

开发先种子42，a1/c1/g1整房间留出，共12次；外部前两种预训练各1次（所有折共享外部公开数据，不含官方），source_control每折独立预训练。选最好的外部变体，在种子2026重验三折，与同种子source_control比较。按两种子平均的min(房间均值准确率,合并五类宏召回)选外部方案；排序再看最差房间、NLL。保留表现好/坏的全部检查点，不按训练准确率挑选。固定末轮，无验证早停。

最终选定外部变体与source_control分别用全48条训练并导出，均非平台已验证升级。低于对照也保留外部研究候选并清楚披露，不把0.37最佳排名改掉。导出ONNX18嵌入权重<100,000,000字节，独立CPU进程验证真实/断包/零输入、数值一致性、平均<.7秒、内存<6GB。最终只将有希望且合规的文件列为可试提交研究候选，用户自行上传；RadioPoints非商业研究条款及Brescia CC BY-SA来源说明随文件保留。

全部数据、权重、日志在D:/huawei2026-experiments/external_upgrade_20261021。C盘只留代码、报告、审计和最终ONNX副本。已有模型不覆盖。

在查看第二种子结果前增加一项固定后处理对照：只比较同一外部方案seed42/2026的等权概率平均，不搜索权重。如果其三折min(房间均值,宏召回)比最好的单模型至少提高1个百分点，且最差房间不下降，才增加第二个全量种子训练并导出双模型。两份权重仅以FP16存储、运行时转回FP32，计算仍为FP32；须独立通过<100MB、<.7秒和数值检查，否则沿用单模型。不会平均不同随机初始化的权重。

另在计算任何融合成绩前登记唯一一个固定锚点对照：平台0.37原宽度seed42与选定外部单模型等权概率融合。开发只能使用原版对应的整房间留出预测（之前已保存），禁止使用全量0.37模型预测开发房间。仅在selection_score比原版与外部单模型两者最大值高至少1个百分点，且最差房间不低于原版时，才允许选择；与已合格的外部双种子方案比较同一selection_score。原版全量权重仅用于最终导出。不存在融合权重搜索。

第二阶段结果出来后的独立后续假设：从头训练的残差接入版本仍低于原版，可能干扰了原融合表示。因此再做一个固定方案：原版概率占90%，两个仅在外部数据预训练、从未接触官方标签的时间专家概率均值占10%。不搜索比例、不对专家用官方数据微调。开发使用已保存的原版逐房间留出预测，专家仅提取各留出窗输入。仅在min(房间均值,宏召回)比原版高至少0.5个百分点、且最差房间不下降时，才进入最终候选选择；否则不导出此后续方案。若通过，将重新按原版完整协议训练seed42全48条基础模型，再接入本轮已训练的外部专家，全部FP32、无需大模型双份权重。这个后续检验属于已看过开发结果后的探索，不宣称盲测。
