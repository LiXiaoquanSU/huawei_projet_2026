大文件根目录：`D:/huawei2026-experiments/next053_20261025`。报告：`docs/NEXT053_20261025.md`。

依次运行项目虚拟环境中的：

1. `prepare.py`：从实际0.54图提取ONNX预处理，生成960窗缓存；8个原始窗验证12视角的通道特征映射误差为0。
2. `run.py`：5套教师×11种配置，含来源、整房间代理、适配器、频率镜像、意见融合。权重引用既有paired训练，无本轮新训练。Gcal相关迁移对照明确不算严格独立代理。
3. `ordinal.py`：2种额外固定序数融合，都失败，不进入最终候选。
4. `export_batch.py`：可单独生成0.54批量推理等价原型作开发检查；不具有新的平台分数。
5. 保存选择`transfer_low_guard`后，调用`export_batch.assemble`生成唯一候选。此方法只在0.54最终预测0/1时接管，原2/3/4完整分数保留。
6. `audit.py`：全部960原始ONNX，输出同图原0.54风格对照，逐条验证高人数原分数不变及独立网络参考。
7. `tools/check_candidate.py D:/huawei2026-experiments/next053_20261025/export`：独立CPU接口/数值/耗时/内存。
8. `publish.py`：全部通过后复制一个未评分候选到C项目，保留0.54为已评分最佳。
