# 从0.54向0.60的首轮实验

大文件目录：`D:/huawei2026-experiments/g60_20261025`。完整说明见项目`docs/G60_EXPERIMENTS_20261025.md`。

顺序运行：

1. `run.py`：5套冻结教师的12视角缓存、5种固定聚合、10个小型可靠性模块训练。若已有缓存/fit会复用，不重新训练。
2. `routes.py`：三条固定共识路由例外，无阈值扫描。
3. `combine.py`：复用上一轮paired训练权重，比较0.5参数更新与12视角组合，两种子及平均。
4. `quantized.py`：回退到0.25、seed42，按原FP16/FP32存储精度重测5套。
5. `export.py`：直接替换054图中对应20个编码器张量，全部节点/路由不动；原始输入审计全部改判、低间隔和各记录首尾窗。
6. `tools/check_candidate.py D:/huawei2026-experiments/g60_20261025/export`：独立CPU进程接口/资源检查。
7. `publish.py`：复制唯一探索候选，登记空平台成绩，最佳继续054，目标改为060。

严格筛选没有任何方法完全通过。最终文件明确作为探索对照，而非已证实改进：四分之一编码器更新在两代理提高、两代理持平，但来源4人类损4窗。切勿省略这项限制、将来源正确率当成隐藏成绩，或覆盖原0.54。
