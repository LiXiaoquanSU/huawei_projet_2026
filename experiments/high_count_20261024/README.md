# 高人数条件读出实验

原始0.48为底座，单独处理2/3/4边界，不叠加同为0.48的temporal80方案。

- train.py：2房间×2新头种子×普通/成对损失×实际/独立代理证据，共16次训练，再做2次全数据拟合。26参数条件高人数读出，基于现成四视角证据，不增加主干。
- build.py：固定双时间视角去偏置一致性对照，仅存D盘。
- export_learned.py：将普通损失训练的新读出接到原0.48实际ONNX中间张量；原节点/参数逐项保留。只允许底座3/4改为更低的2/3，条件概率≥0.6。364个可能改变的原始窗口直接核对，另外596个由门控及原图一致性证明输出不变。
- references.py：用原0.48中间证据与独立NumPy公式生成参考。
- tools/check_candidate.py：对D盘learned_export目录作独立单输出CPU检查。
- report.py：所有检查通过后，复制一份学习版候选到models/high_count_20261024，并记录未评测状态。

大文件与逐记录结果位于D:/huawei2026-experiments/high_count_20261024。依赖本机历史缓存/权重/原始数据；重新运行训练会覆盖本轮同名辅助权重。独立代理没有收益，实际模型的全数据编码器看过外层标签，所有诊断不能冒称隐藏成绩或独立泛化保证。
