# 房间与人数混杂研究（2026-10-21）

数据与结果根目录：`D:/huawei2026-experiments/room_support_20261021/`。
这批代码独立于提交模型；没有改写 src、现有 ONNX 或平台成绩。

依次运行，使用项目 `.venv/Scripts/python.exe -X utf8`：

1. `acquire.py --download`：固定 Git tree SHA 下载 RadioPoints 三房间各0—4人15条记录，保留来源、大小、SHA256、Git blob。
2. `prepare.py`：按 Intel 5300 官方格式解码、天线重排与功率缩放，按实测微秒时间戳切3秒窗，保存实际2Tx×3Rx×30复数矩阵及96维共同时间描述。
3. `official_and_pilot.py`：官方48条记录的房间×人数表；同样提取96维描述；固定参数RF做官方5折无/有RadioPoints对照及外部3折，共13次拟合。未知房间记录不进入开发折，留给最终全量监督。
4. `dataport.py`：记录80MHz论文正式DataPort入口的访问要求。文件需要订阅登录，尚未下载，不绕过。
5. `sharp_public.py --download`：作者另行公开的SHARP原始档案，抽取S1a/S6a/S7a（卧室、客厅、实验室）的E/L/W/R文件；不是DataPort完整数据。保留CRC、SHA和许可页面。用Windows curl/Schannel正常校验证书，无禁用TLS。
6. `prepare_sharp.py`：核对作者源码规定的四天线交错排列及fftshift后242有效频点，保留完整包组清洗索引。没有真实包时间戳，明确使用论文名义6ms，不当作实测多普勒。3个物理房间分别留出，做人数存在/活动两项RF诊断，共6次拟合。
7. `report.py`：生成最终审计与中文报告，核验文件、模型身份及源代码，保存源码快照。

依赖：numpy、scipy、scikit-learn、blosc2；均来自当前项目环境。下载只读取公开源。脚本中的网络与D盘写入在本环境需通过执行工具申请沙箱扩展。

共同描述只用于辅助研究：16种幅度变化统计，每种聚合六个真实链路/频点分位数，合计96维。时间统一到50Hz前低通；这是幅度调制频谱，不是去除硬件相位误差后的物理多普勒。它不能恢复缺失的天线、1024子载波或高速细节，也不能直接取代0.37模型的完整输入。

严格按整条记录、整间房间分折；同一记录的窗口/天线不跨训练验证。三个RadioPoints房间每类只有一条记录，窗口数不等于独立采集次数。试验参数固定，未按验证成绩反复调参。这批RF诊断不等于0.37深度网络的新训练结果，不能与平台分数直接比较。
