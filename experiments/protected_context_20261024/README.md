# 主模型与上下文模型的保护融合对照

已完成：8次新训练，第一种子未通过逐类召回门槛，没有跑第二种子，也没有导出候选。[完整结果](../../docs/PROTECTED_CONTEXT_20261024.md)。

目的：检验上下文结构能否在保留0.47式保护规则的前提下补充错误；修正上次把同一固定偏置直接移植到其他训练折的问题。

在项目根目录运行 `.\.venv\Scripts\python.exe -X utf8 experiments/protected_context_20261024/run.py`。数据与权重记录到 `D:/huawei2026-experiments/protected_context_20261024`。需要本机D盘原始比赛数据、已有特征缓存和GPU。本轮不使用外部数据或U数据。

- 外层整房间留出：a1/c1/g1为开发，e1为压力检查。unknown不参与。
- 内层校准：训练侧每个人数固定抽一条完整记录，共5条；其余记录训练。三个集合源记录互斥。校准集每类一条记录并不能代表所有房间。
- 两个结构各重新初始化，固定原先5轮训练配方。主模型4视角，上下文模型1视角；推理采用大权重半精度存储对应的取整精度。
- 每份模型用自己的校准记录拟合带正则的偏置/温度，固定150步，无外层标签拟合；报告无校准对照。
- 固定75/25概率融合，保护主模型最终预测的0/2。另设无保护融合诊断与只在一致时融合的类别不变对照。
- 第一个种子42通过预先规定的逐房间/逐类门槛才跑2026；没有通过就停止，不根据失败结果现场扫权重或改阈值。

这是新权重代理实验，不能继承真实0.47成绩，也不直接替换其偏置。训练集比过去整折训练少5条记录，所以与历史折指标不能作严格同条件比较；有效比较限于本轮同一划分下的主模型和融合。旧验证房间被多轮研究重复使用，不是全新独立测试。该脚本不自动导出或提交模型。
