# 重叠窗口数据扩展，暂停结构探索

用户要求转向数据。timefreq_mixer结构训练在本消息到达前已完成，本轮不继续导出/扩展它；权重与结果保留。新工作不改网络结构。

连续CSI不是图像视频：48条×12000帧；旧每600帧不重叠切窗，共960。保持600帧接口，按ATI真实时间累计，每1s/0.5s开窗；两版本都并入旧600步长锚点。每窗最后ATI置0，不能跨原记录、不能跨标签。CSI记录人数恒定是本题标签条件。预处理与旧缓存一致，旧锚点缓存逐位复用，每原记录两个锚点从原始数据重算校验。D盘每记录npy分片，避免内存巨量拼接。

意义是更多时间起点与过渡位置覆盖，不能增加独立房间/人数样本。重叠窗口不允许随机拆分训练/验证；保持a1/c1/g1整房间留出，unknown不进开发，源记录ID不交叉。主要测试仍是原不重叠窗口，作为相同难度对照；密集0.5s测试只作附加诊断，按记录报告精度与相邻一致率，不能把多个重叠预测当独立实验。每布局一房间条件仍在。

三份既有结构：cross_events(平台0.39)、context_events(0.39)、mixer(0.33)。从零初始化，沿用原loss/optimizer/epochs（前二5轮，Mixer12轮）。首先保持每epoch抽样数=旧非重叠训练窗口数，确保梯度更新次数相同，比较窗起点变化；按类别/房间/原记录等权抽样，再在记录内抽窗，避免更长记录权重放大。

预设33次拟合：3模型×2步长×3房间seed42=18；每模型最佳步长seed2026三折=9；每模型最佳步长seed42 e1=3；三模型各全48记录=3。按min(主测试三房间均值,宏召回)、最差房间、NLL选择步长。最终全量种子固定匹配已测文件：cross42/context2026/mixer42，不按验证挑种子。比较旧同种子模型，复算每模型seed42a1预测校验。固定末轮，不挑epoch，不加载全标签权重做开发。

旧预测是同房间留出旧非重叠窗口，新模型另评估密集留出窗口；原始训练和验证记录完全隔离，相关样本数不当作独立样本数。密集测试不能随意重切成更容易的集合。结果若无改善，明确报告，不以训练高分称升级。33次仍是固定更新预算，可能没有遍历所有新增窗口；实际覆盖数单独报告，后续增加预算需另有对照。
