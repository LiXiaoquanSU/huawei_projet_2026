实验结果、物理解释的边界和负面结果见[报告](../../docs/SUBNET_EXPECTATION_20261025.md)。大文件保存在`D:/huawei2026-experiments/subnet_expectation_20261025/`。

5. `complete.py`同步模型说明、队友文件夹和模型表。已测0.54始终保留。
