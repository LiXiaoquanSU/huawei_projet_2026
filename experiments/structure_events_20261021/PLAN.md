# 结构改进：局部事件与多时延频段关系

先登记上一轮文件SHA21e7a4d…181b83a的平台0.35；仅对应同字节文件，原0.37不变。

动机：外部迁移0.34/0.35未超过0.37；不继续加外部监督。已有普通LSTM/TCN/频率集合/单协方差失败，避免把换名字当新模型。此次关系矩阵由真实幅度/相位的频率轴直接计算，在多个时间延迟上保留共同变化；与旧学习后32通道零延迟协方差不同。事件路线保留150时点、软事件出现频率、五段统计和转移，避免仅整段均值/标准差丢失局部扰动。没有事件或速度真值，不宣称中间层直接检测单个人。

依据：CrossCount https://arxiv.org/abs/2007.03175 强调时间遮挡模式；DeepCount https://arxiv.org/abs/1903.05316 结合CNN/时序，但其在线进出校正不适用于独立600帧接口；TCN https://arxiv.org/abs/1803.01271 仅支持局部时序建模动机，不是本模型的人数效果证明。新结构为自设计适配，不复现论文分数。

预先固定：baseline、events（仅替换时间路线）、relations（仅增加潜变量关系修正）、combined（两项）四方案。官方缓存同一原预处理、五轮AdamW4e-4/weight_decay.01/batch32、原loss与原平衡采样，不用外部或U。a1/c1/g1整房间开发，unknown不进入开发；seed42筛选，按min(房间均值,五类宏召回)、最差房间、NLL排序。最佳新结构与baseline用seed2026复验，再做e1压力测试（只有0/1，不作完整五类排名）。不搜索融合权重、不从不同轮数挑最高分。若新方案均失败，仍导出相对最好的新结构作为用户要求的研究候选，明确未证明超过0.37。

最终对选中新结构的开发领先种子进行全部48记录训练；记录池960窗及实际采到窗口分开登记。旧模型不覆盖。ONNX固定float32接口、18opset、内嵌权重、<100MB，本机真实/断包/零输入一致性、CPU<0.7s和峰值<6GB检查。日志、权重与输入数据留D:/huawei2026-experiments/structure_events_20261021，代码/轻量核验/新候选留C。平台成绩不推断。
