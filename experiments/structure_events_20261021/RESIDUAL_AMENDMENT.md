# 压力测试后的单次结构修订

初始四方案和两种子复验完成后，events在e1 seed42压力测试为0%，60窗全预测3人；三房间均值提升不能抵消这一已知退化。保留原21次结果，不改写为成功。

增加一个有明确原因的event_residual变体：原时间注意力完全保留，并行事件编码器通过256维sigmoid门相加，门初始-2（约11.9%）。不借用全量0.37权重，仍从头随机初始化、官方源训练；每折原注意力、三空间路线初始值与对应baseline一致。训练预算和loss不变，避免把预训练/冻结混进本次结构解释。

追加seed42/2026各三房间、seed42 e1共7次开发拟合。最终在events与event_residual中，优先保留e1准确率不低于原baseline（33.3%）的方案，再按两种子平均min(房间均值,宏召回)、最差房间、NLL排序。如果两者均不满足压力门槛，也按预定排名保存一个研究模型，但明确不作为已经改进的方案。候选种子按对应三房间开发分选择，全48重新训练。最多再增加1次全量拟合，总计29次；不继续围绕e1搜索多套模型。

e1是反复分析的开发压力集，不是新盲测。这次修订由观察失败触发，应在报告中与初始预设四方案区别记录，不将修订后分数宣称独立确认。
