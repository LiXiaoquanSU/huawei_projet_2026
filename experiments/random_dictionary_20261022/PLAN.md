# 第四条独立路线：固定随机字典

新增原因：三个新神经骨干首种子训练高分但跨房间失败。这里不训练骨干，以固定随机滤波器产生特征，再训练小线性读出，检验限制表示自由度是否有帮助。不是给0.39加分支。

来源ROCKET https://arxiv.org/abs/1910.13051 ，随机卷积+最大值/正响应占比+线性分类。这里是多通道稀疏随机卷积、固定核长7/9/11和膨胀1/4/16各64核，共576核；幅度/相位动态信号288通道，最大值和正响应比例1152维，加17统计量。与原ROCKET核分布/核数不同，不称完整复现。没有训练CNN/Transformer，不加载旧权重。

标准化中心/尺度仅由当前训练折计算；类别/房间平衡权重与前面一致。加权ridge，预先固定lambda=10，不看验证选择正则；在N×N对偶空间求解。输出线性得分再logsoftmax以统一ONNX接口/NLL（不是校准概率）。随机特征可预计算所有输入，因为变换不拟合数据；标签和标准化只用训练折。

种子42/2026分别a1/c1/g1及e1，共8次开发拟合；按同样的min(房间均值,宏召回)评估。与三种新神经骨干选出的候选比较，如果更好则全48记录拟合一次并导出。本阶段最多9次拟合。只有算法层面一致划分，不声称不同优化器/预算是纯架构消融。原最佳0.39保留。
