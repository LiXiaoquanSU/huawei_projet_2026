# 同房间人数顺序监督：2026-10-29

本轮完成18个描述量的记录级趋势诊断，以及三折纹理网络对照训练，共60轮。只增加同房间、不同记录的人数顺序损失，结构、种子、数据、抽样与原纹理版相同；没有用测试标签调整特征或训练轮数。

## 为什么不直接使用运动强度数人

a1与c1共同覆盖1—4人；a1仅11条、c1仅12条对应记录。运动能量与人数Spearman相关在a1约−0.886，在c1约+0.420；幅度高时间频率能量比例分别约+0.867、−0.402。简单的“人数更多→运动更强”不是两房间一致的规律。

这是小样本探索性相关，不能视作因果。18项描述量逐项检验存在多重比较，未用于挑选测试集上表现好的模型输入。缓存特征的秩不等于人数，时间频率组指窗口内周期数而非精确物理Hz。

## 单一改动

原纹理结构543万参数不变。在每个训练batch中找同一已知房间、不同记录、人数不同的样本对。对较多人样本的预测期望人数，施加高于较少人的软约束：0.2×softplus(0.5×真实人数差−预测期望人数差)。它约束学习结果的顺序，不强迫某个原始能量指标单调。未知房间不拼成同一域。

配对只在训练记录中进行；推理不输入房间ID、不需要参考记录，也不增加模型头。其余仍为20轮、AdamW0.0003、batch24双视图、源校准均衡NLL选权重。房间匹配不能消除布局或采集批次混淆，仍需跨记录与跨房间验证。
