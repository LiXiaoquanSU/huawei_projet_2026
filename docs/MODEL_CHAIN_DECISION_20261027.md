# 完整识别链的研究决策

本文件是模型研究方案，不是训练结果。当前没有证据证明某个网络全局最优；目标是选择假设最少、可逐步检验的路线。平台最佳仍0.54。

## 需要修正的认识

1. 生成原因清楚，不代表逆向推断唯一。人数、位置、活动、房间和采集条件共同影响CSI；从约3秒观测未必能唯一还原全部因素。
2. 给潜变量命名为“环境”“活动”不等于实现因素分离。Locatello等说明无监督解耦需要模型和数据的额外归纳假设；它不证明本题绝对不能分离，但否定自动分离的保证。
3. 不能无条件消除房间信息。人数与房间标签分布偏置严重，强行对齐整体分布可能同时删除人数证据。Zhao等提供相关理论反例，并非直接证明某个本项目算法必然失败。
4. 本地原题记录明确S/T物理房间不相交；管理员所说同分布没有明确撤销该条。整房间验证仍是主要开发压力测试；整记录验证检查可学习性，不能替代前者。现有留房间还同时留layout，代表性有限。

## 选择的识别链

测量质量与采样时间 → 保留稳定状态和时间变化的多尺度表示 → 在场景上下文条件下整合跨接收通道证据 → 联合比较0—4人假设 → 概率及不确定性检查。

这是一条条件化的判别研究路线，不要求先精确重建房间、分出每个人，再数人数。完整物理生成模型可用于解释假设，但当前48条监督记录不足以支持宣称完整恢复环境/活动/个体位置。

### 最小可检验实现

- 输入：单个600帧CSI、ATI、有效载波掩码。没有房间ID、空房参考、邻接测试样本或跨调用记忆。
- 观测层：保留原始尺度描述、频率形状、天线对复关系及实际时间。归一化表示与必要的尺度统计共存，不一次删除所有背景。
- 表示层：稳定状态表示与变化表示共享基本编码规则；时间变化考虑实际ATI。名称只描述输入/计算，不声称分别等于环境和人体。
- 联合层：上下文描述用于有界条件化和证据可靠性判断，跨天线关系与时间证据共同参与。相位对方向、共轭必须随通道排列一致处理；不假装三个Rx来自三个独立房间视角。
- 输出层：一个共同训练的五类人数头，保留多种活动条件下同一人数的可能性。首版不采用不可逆的空房硬门，也不把呼吸峰、矩阵秩、运动峰数直接当人数。
- 不先建完整VAE/重建生成器；重建好不等于人数识别好，且额外潜变量含义缺乏监督。

与此前的冻结054后加修正不同：这是全路径共同学习的假设；但共享编码、关系建模、多分支已经尝试过，不能靠重新命名宣称创新。必须明确检验上下文条件化和训练约束是否带来可复现机制收益。

## 训练与识别链的对应关系

1. 从已有有标签数据开始；完整记录划分先于窗口生成。记录内不同窗口仅约束人数预测一致，不要求活动表示相同。
2. 在同房间不同人数记录之间学习人数区分，减少纯房间查表捷径。这些记录不是同一受试者/位置/动作的受控干预，不能声称构造了因果配对。
3. 同人数跨房间的比较只在实际有类别支持时进行。0/1人覆盖较多；2—4人只有a1/c1，不能对不存在的组合强行施加约束或伪造标签。
4. 初始训练只保留分类目标与明确人数保持变换的一致性。上下文条件化、跨记录约束等逐项加入，保留同预算、同容量、同划分对照。
5. 不让所有房间整体分布相同，不让同房间所有记录的人数表示相同，不把全部无标签U用于人数伪标签。官方U可能包含室外经过者；以后使用时须单独检验前提。
6. 不把偏置搜索和保护规则放在首轮机制研究中。原054仅是参照；如用其全量权重，训练集准确率不能当独立验证。

## 判断方向成立与否

允许早期准确率低，但必须看到可复现的环节证据：记录内人数稳定性、跨种子一致性、同人数跨环境的迁移，以及在同预算对照下环境依赖是否下降。不能通过输出恒定人数获得一致性；必须同时检查类别可分性。

若仅整记录改善、留房间持续崩溃，不能解释成“尚未完成所以一定正确”。若环境识别能力下降但人数区分也消失，也不算成功。低分的好假设应保留，无法被证据区分的说法应修改。尤其不能在高人数环境支持不足时承诺结构能够补足所有信息。

## 文献依据与适用边界

- [Widar3.0，MobiSys 2019](https://cswu.me/papers/mobisys19_widar3_paper.pdf)：以速度表示支持跨域手势识别。启发是先建立物理意义明确的表示；它研究手势，不是静止/日常活动混合的人数分类，不能直接移植结论。
- [Passive People Counting using Commodity WiFi，2020](https://hub.hku.hk/handle/10722/303712)：作者机构摘要描述连续多人呼吸轨迹跟踪进行准静态计数。本次未取得全文；不能假定这种连续轨迹方法在独立约3秒样本中成立，也不据摘要臆测具体最短窗口。
- [WiCount-DASL，2026](https://research.polyu.edu.hk/en/publications/wicount-dasl-domain-adversarial-semi-supervised-learning-for-wi-f/)：本次核验作者机构摘要，涉及静止人群计数、域对抗半监督和类别自适应伪标签阈值。说明相关研究存在，不证明其无标签假设匹配本赛题。
- [Locatello等，ICML 2019](https://proceedings.mlr.press/v97/locatello19a)：潜因素自动解耦缺乏一般保证；模型命名不等于可辨识性。
- [Zhao等，ICML 2019](https://proceedings.mlr.press/v97/zhao19a.html)：标签边际差异下，学习域不变表示存在误差权衡，整体分布对齐不能保证迁移。

本地证据：TIME_PHASE_DETAIL_20261027.md（整记录改善但整房间恶化）、DETAIL_RESIDUAL_20261027.md（40组受限修正均未超过基线）、COVARIANCE_20261026.md（仅归一化变化表示失效）、TEST_STRUCTURE_AND_ROADMAP_20261025.md（原题和类别×房间覆盖审计）。

决策：优先研究保留状态与变化、由上下文条件化的联合人数推断；暂不把完整因素分离、逐人体检测或呼吸计数作为必经环节。该决定是当前证据下的研究优先级，不是已证明最优的模型。
