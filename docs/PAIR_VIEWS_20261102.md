# 借鉴054的候选人数比较实验（2026-11-02）

已证实的054经验来自原权重不变时的条件多视角融合，不能据此推断扩大网络有效。本轮用类共享的两两比较器读取12视角证据，比较结果强制反对称，再汇总为每类±0.5以内修正。没有人数ID/房间ID输入；保留保护规则与允许修正全部输出各设一组，并以将12视角压成相同均值的同参数对照检查新增视角信息。

4个留房间代理×4方案×2种子=32次训练，每次200步。教师核验fit权重哈希；沿用其源校准偏置/温度；修正器仅用源fit记录训练，仅源校准选0/20/50/100/200步。实际054全量权重不用于留房间验证。旧开发房间已反复使用，不能把小幅改善视为独立泛化证明。

## 结论与校准排查

保留保护的比较器276/880，低于基线278/880；允许修正全部输出290/880（两种子），但均值控制292/880与289/880，未证实视角差异信息有效。不能把修正所有输出的微小代理提升当作可发布候选，历史无保护全融合平台曾下降。

602个代理错误中389个所有视角均错，216个所有视角前二均无真值；这不代表隐藏测试的错误分布，也不是新模型的准确率上限。

固定权重的校准对照：原校准278/880、无偏置无温度221/880、仅温度245/880、仅偏置252/880、源均衡先验258/880。移除校准没有解除主要失败，尤其0/4类别仍很弱；不把问题单独归因于偏置。完整数据保存在D盘同目录calibration_audit.json。
