# 原题、隐藏测试结构与下一阶段路线

本次重新读取本地原题PDF（8页）和提交指南，重算官方S/U元数据，结合逐文件平台成绩。没有读取隐藏测试样本，没有开始新训练。所有关于隐藏分布的推测均与原题规定分开。

## 1. 原题明确的测试结构

|事项|原题内容|对我们的影响|
|---|---|---|
|测试房间|与有标签训练集S的物理房间不相交|记住房间背景不够，随机分窗不是合适主验证|
|无标签U|允许与测试T共享物理房间，但不保证共享；S/U/T样本互不重叠|同时考虑目标房间适应与完全新房间泛化，不能把U样本认作T原件|
|布局layout|T的布局来自训练数据的布局家族；公开与私有T按layout互斥|“训练数据”包括S和U；不能擅自缩小成只来自S的五类layout。公开榜规则未必适用于私有布局|
|公开/私有分数|公开榜日常反馈，私有集用于最终排名；原题称二者总体分布相同|同分布与布局分组不同可同时成立，不是同房间随机切两份|
|单样本|600连续帧，约200Hz，约3秒；0–4人恒定；无紧邻室外路人经过|人数稳定，但姿态/位置/活动可变化；不必把跨窗口人数变化当主要任务|
|CSI|80MHz，1Tx×3Rx×1024子载波，复数；ONNX最后维为实部/虚部|隐藏输入格式不是未知天线数、未知子载波或未知实虚部|
|ATI|微秒；相邻帧间隔不均匀；末项0为padding|时间建模应使用ATI，不能只按帧号当绝对等间隔|
|硬件|路由器相同；相同layout内部署方式相同|硬件异构不是原题首要变化，环境与部署/布局变化更直接|
|模型接口|只有frames与intervals，没有room/layout/identifier输入|不能指望推理时收到真实房间ID或相邻样本顺序；常规ONNX调用不能依赖在线累计整个测试集的类别配额|
|资源|单文件嵌入权重<100,000,000B，CPU ORT，内存6GB，平均每样本<0.7s|应把算力花在有效泛化而非盲目填满100MB|

## 2. 官方S/U的实际覆盖

S共48条，每条12000帧，约60秒。600帧非重叠窗只是每条20窗，不是20个独立房间。

|S房间|layout|0人记录|1人|2人|3人|4人|
|---|---|---:|---:|---:|---:|---:|
|a1|a|1|2|3|3|3|
|b1|b|1|0|0|0|0|
|c1|c|0|2|3|3|4|
|e1|e|2|1|0|0|0|
|g1|g|7|10|0|0|0|
|unknown记录|unknown|0|3|0|0|0|

U共150条：d1/d 8条，h1/h 14条，i1/i 17条，j1/j 4条，u1/u 55条，v1/v 47条，unknown 5条。队友26种子表只统计前145条、2900窗，未包含unknown。

**新确认的重要限制**：已知元数据里，S的五个房间各对应不同layout，U的六个已知layout也与这些不同。我们没有同一已知layout下两个带标签房间供验证。因此当前“留一房间”同时也是留出一个带标签layout；而老师允许利用训练U覆盖的布局/房间信息。这使单一留房间分数不能完整模拟所有官方测试情形。

unknown不是一个物理房间或一个共同布局的名字。三条S、五条U的unknown记录不能简单合并为同域，也不能推断它们全部互异或与其他房间没有关系。

## 3. 能推断什么，不能推断什么

### 有依据的推测

- 公开测试整体五类接近均衡：队友记录四个常量0/1/2/3分类器各约0.20，结合原题普通accuracy提供支持。但它不是官方逐房间配额；第五类比例也只有基于总和及显示精度的近似推断。
- 原模型的输出校准与特定输入顺序敏感性构成可利用的误差：0.37→0.44校准、0.44→0.47视角/保护、0.49→0.54完整fallback均有平台记录。
- 当前开发分数代表性有限：两次局部改进分别+1.82pp、+3.64pp，平台都0.53。最后一次净32中，0人0、1人+8、2人+25、3人−1、4人0，并非全类别进步。

### 仍然未知

- 哪些U房间属于公开或私有T、T是否覆盖全部U房间，以及各房间类别分布。
- T的窗数、采集数、窗口重叠方式。两位小数的分数不能证明只有100个样本。
- 原054在隐藏集具体错在哪些类别/房间；不能用本地错题替代隐藏错题。
- Rx变换有收益不证明老师把Rx顺序打乱；时间反转有收益不证明老师给了倒放输入。它们可能缓解旧网络的顺序敏感性，而非发现隐藏输入格式。
- 公开/私有精确类别比例与具体活动强度，不可从“同分布”推出每房间各类20%。

## 4. 我对问题本质的判断

更合适的表述是：固定采集接口下、监督覆盖很偏的跨房间/跨布局人数分类，同时允许利用部分目标侧无标签环境信息。不是从CSI逐个检出人再相加；静止/慢动/快动标签和真实房间面积都未提供，不能把辅助头的名字当作真实检测能力。

CSI同时含环境背景、人体影响、运动和采集扰动，彼此耦合。静止人体也会影响静态信道，不能把全部静态频谱视为垃圾；NT输入斜率校正0.45及本轮去静态子网明显退步，都是反例。更可靠的目标是学会在不同环境条件下使用人体相关证据，而非一次预处理“删除房间”。

## 5. 下一阶段优先级

### A. 先建立两套匹配原题的验证，冻结选择规则

1. **完全新环境**：目标房间/layout的所有记录都不能参加训练或无标签适应。按采集记录划分，报告每房间×人数支持度、混淆矩阵与净纠错，不能只报总体正确率。
2. **有目标环境U**：留出目标房间后，将部分完整采集记录隐藏人数标签，允许做无标签适应；用另一批采集记录的标签评估。两批采集不重叠，划分尽量不依据目标人数标签。房间只有一条记录时不能硬造独立适应/测试两组。

新增第二套不是偷看测试标签，而是模拟原题允许U∩T房间重叠的情形。此协议在现有房间上仍属开发，不能宣称新盲测。真正的新盲测需额外独立采集/标注房间。

一个60秒记录中的多窗口适合当训练增广，但不能在适应/验证两边随机拆。模型要同时满足两种情形，避免只对可识别U房间有效。公开榜与私有布局不同，需要特别警惕依据公开成绩反复选出布局专用规则。

### B. 先更合理利用官方U，而非再无差别增加外部数据

先审计每房间的有效载波、Rx质量、时间间隔、信号幅度、跨记录变化与054的视角分歧；区分采集异常、类别先验变化和表示变化。U没有标签，预测分布/置信度/聚类都只是诊断，不是准确率。

训练可沿“环境表示+人数表示”分工：同房间不同采集帮助估计背景共性；同一恒定人数记录的不同时间窗/合适视角约束人数一致。**不能让同房间不同采集的人数表示强行相同**，因为真实人数可以不同；也不能把背景原型叫作真实空房参考。

此前官方U一致性/自训练已经尝试且没带来稳定突破。下一次需要按上面两套验证区分目标环境可见/不可见，而不是把相同损失再重跑并改名。对伪标签保守处理，对类别覆盖差异使用条件化约束，保留原054的监督/蒸馏锚点。

盲目让所有房间的整体表示完全一致可能把人数差异一起抹掉。Zhao等的理论说明标签边际分布不同时，不变表示与分类误差存在权衡；CDAN提供按预测类别与不确定性条件化适应的思路，但不是本题有效性的保证。

### C. 结构围绕成功的输入关系，不围绕参数量

值得研究的长线结构：共享Rx编码器，保留天线对的复相关/相位方向关系，通过置换等变的关系建模再汇聚人数证据。不是独立处理三个Rx后直接平均；交换Rx时必须一致处理相位共轭/符号及天线对关系，不能破坏空间证据。Deep Sets的集合不变性提供构造工具，不能证明任意天线乱序都物理等价。

这与以前“十二视角特征后再加注意力”的失败方向不同：它从输入天线关系上限制顺序依赖。不过全新初始化仍可能丢失原权重优势，所以先做原054锚定、零初始化残差或分支分解的对照，不一下替换整个底座。

如采用蒸馏，应承认已有0.29/0.31失败记录。可先只近似完整fallback的群平均，原v0/v45保护仍保留；不能强迫一个全置换不变学生精确拟合含原视角优先的非不变最终规则。压缩首先要求行为保持，不能把变小当作准确率升级。

### D. 新数据的价值看独立环境与协议匹配

最缺的是其他房间里的2–4人，以及同一布局下不同物理房间的有标签记录；这比把已有48条切成更多窗口更重要。若能获得同硬件/80MHz/3Rx/复数CSI与可用ATI的数据，优先补这些缺口。外部其他频宽/天线/场景数据需独立适配与对照；已有外部训练0.34/0.35，不能再以下载GB数量作为进展。

## 6. 建议的下一轮具体顺序（尚未运行）

1. 固定原054对照；建立两种验证协议，公开每折房间×人数及采集数，保留全量训练最终提交模型不变。
2. 审计官方U的背景/采集差异和054分歧，明确它们支持哪一种偏移假设；不根据无标签均匀度评冠军。
3. 做一个小而受约束的环境适应模块，分别测试有/无目标环境U；只用安全视角一致性与可靠伪标签，保护原模型行为。将“是否用U”“是否条件对齐”“是否校准”分开对照。
4. 只有这些验证支持后，再训练输入关系等变的结构/残差；不根据反复开发的+几十个窗口承诺平台0.60。

继续扫固定偏置、扩大模型、重复当前辅助分支，不是本阶段最高优先级。0.60仍是目标，没有证据保证下一个模型能达到。
