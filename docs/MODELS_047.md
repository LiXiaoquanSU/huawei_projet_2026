## 一、确定事实：没有换掉基础模型的知识

相对原0.44，两个文件都完整保留全部178个initializer，逐字节一致，包含已学习权重和原Udirect偏置。大版只增加索引和混合系数等固定常量。

进一步逐个核对网络副本：小版4个、大版12个，每个副本2259个基础节点；去掉命名空间、把其外部输入映射回frames/intervals后，**所有节点及属性（包括Constant张量）逐字节与0.44一致**。这比只看文件名或元数据更强，证明新增部分不是重新训练的网络或修改后的基础卷积/注意力。

小版总9061节点、大版27177节点。较大的文件主要包含更多重复计算图和固定常量，基础权重在各视角间共享；文件变大不代表学习了更多参数。

## 二、具体推理逻辑

令f(x)为0.44的五维输出，它是原概率的log分数加固定类别偏置b。R为时间反转，P为接收天线通道排列。

**时间视角：** 对每种排列P，计算

`g(Px) = log((exp(f(Px)) + exp(f(RPx)))/2)`。

反转CSI帧索引为 `[599,598,...,0]`。时间间隔不是简单倒序，而是 `[598,597,...,0,599]`，最后的padding位置保留。这使帧间间隔与反向帧序对应。

**小版：** 先看原天线顺序的时间平均g(x)。若它预测0或2人，保留g(x)；否则，将g(x)与天线顺序210的g(Px)再作exp→平均→log。对应原/反向时间 × 原/反向天线，共4个完整视角。保护的是原顺序的**时间平均结果**，不是直接保护原0.44一次前向的结果。

**大版：** 对012、021、102、120、201、210全部六种通道排列各算正/反向时间，共12个视角。先在图内重建小版结果；若小版预测0或2人，保留该结果，否则取全部六种g的exp平均再log。

这里的保护只依据预测类别，没有读取真实标签；也没有置信度阈值。它不是在运行时知道哪些样本正确。若被保护结果原本错了，这个规则同样会保留错误。

**平均的细节很重要：** 文件使用exp(log分数)后平均，不是直接平均logits，也不是每路先对带偏置分数softmax再平均。因为每个视角共用偏置b，可把它理解为“先平均未校正概率，再加同一偏置”。每路先softmax会带入各自不同的归一化因子，不保证等价。

普通Where并不等于条件跳过整个神经网络计算。图里所有输入分支仍需提供结果；从本机耗时看，大版确实有明显计算代价，不能把“保护0/2”理解为0/2样本只跑一次基础模型。

## 三、为什么可能成功

1. **接收编号不应直接决定人数。** 同一份CSI仅交换3个接收通道的编号，并没有增加或减少人；基础CNN/相位组合却可能对通道顺序敏感。多排列预测可减弱对某一种输入排列的依赖。这是合理机制解释，隐藏集是否有通道顺序差异仍未知。
2. **计数任务通常不需要判断播放方向。** 对标签在窗口内固定的记录，反向查看同一运动过程仍对应同一人数。正反向汇总可缓解网络对某个时间方向的偶然偏好，但并不能推出任意动态任务都允许时间反转。
3. **保护规则限制了修改范围。** 推理增强可能纠错，也可能破坏原本正确的预测；先保留某些类别，是一种控制退步的工程策略。[Shanmugam等ICCV2021研究](https://openaccess.thecvf.com/content/ICCV2021/html/Shanmugam_Better_Aggregation_in_Test-Time_Augmentation_ICCV_2021_paper.html)也观察到TTA即使总体提高，仍可能把正确预测改错。该论文研究的是图像，支持一般聚合风险，不证明本赛题该保护0/2。
4. **保留了0.44已经有效的校准。** 新的0.47没有丢掉之前的偏置，也没有重新随机初始化。当前收益来自推理策略组合，而非必须扩大、重训基础网络。

更准确的结论是：基础模型已有的信号知识还能通过更合适的观察与汇总方式利用。不是网络结构永远无需改进，也不是TTA永远比训练有效。

## 四、哪些原因还不能确定

- 没有老师隐藏标签或逐类混淆矩阵，不能说提升一定来自2人、某个房间或某种运动速度。
- 用户补充了阶段分数：时间反转版0.45，四视角保护版0.47；但没有独立开关保护的同期对照，不能把3个百分点精确分摊给时间反转、天线排列及保护各自贡献。
- 无法仅从文件确定为何选择保护0/2：需队友提供开发依据，不能直接称它们最可靠。
- 0.45中间模型49108已由用户转述队友说明确认，列为用户报告的阶段成绩；仍未收到对应文件，不是独立平台复测。
- 六排列平均的候选分支有对称化意义，但整个带保护模型未必严格天线置换不变，因为保护门本身锚定原顺序。
- 不能由大版也显示0.47就断言更多视角无效；也不能据此宣称大版更好。需要更多未四舍五入指标或逐样本结果。

基础0.44独立运行每个变换，按上述规则在Python中重建两版输出。普通、异常时间间隔、全零3例加30个真实原始窗口，共33例，覆盖0–4人、五个已知房间和unknown。重建与提供文件全部通过，最大概率误差0.000000047。

## 六、与前期经验合起来看

之前重叠窗口、扩宽、联合重训都没有稳定改善；0.40的独立模型融合有小幅收益，队友又通过固定输出偏置到0.42/0.44，再通过多视角与选择性聚合到0.47。下一步的研究优先级应包括输出校准、输入变换下的一致性、以及避免破坏已有正确判断，而不只是增加参数。

当前不启动训练。先收齐队友的策略选择和消融依据：单独时间平均、单独天线平均、有无0/2保护、所有视角与少量视角的对照；同时记录每类收益/退步及运行成本。以后若恢复训练，可把经过验证的接收通道/时间变换作为一致性目标，检验能否把多视角收益压缩到较少计算中；那是新假设，当前还没有训练或证明。
