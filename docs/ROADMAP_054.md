# 从平台0.47向0.54升级：下一阶段方案

**最新平台更新：原视角1人保护版已由用户反馈0.48，现作为新基准，距离0.54仍差6个百分点。** 它没有改变学习权重或偏置，属于推理规则升级。[经验总结](EXPERIENCE_048.md)。下文保留此前实验规划，提到原0.47时表示当时基准。

**实际模型审计后的优先级更新：** 两份0.47本地诊断均为54.06%，但四视角1人召回仅5%，4人召回100%。原0.44→四视角在这些数据上纠正5窗、改错163窗。先做冻结权重的原视角保护消融，再做从已有权重出发的变换一致性微调。下文结构路线继续保留，但不再以代理高人数失败作为扩大模型的直接依据。数字仅为训练来源诊断，平台仍0.47。[完整结果](ACTUAL047_ERROR_AUDIT.md)。

目标是老师平台准确率0.54，当前最佳为四视角49130及十二视角49131，各0.47。需要提高7个百分点，不是本地分数达到某阈值就算完成。以1000个样本作说明，需要净增加70个正确判断；若完全不损坏已有正确判断，约需纠正原错误的13.2%。这只是目标量化，不是可实现性证明。

## 成功经验与边界

- 原0.44结构/权重提供基础信号表示；时间反转版49108到0.45，四视角保护版49130到0.47。十二视角49131仍显示0.47，不能假定继续增加视角就会提升。
- 原权重不变的固定偏置曾有效；偏置跨不同checkpoint直接迁移则造成代理类别塌缩，不能把一组五维常数当作通用改进。
- 无保护12视角平台0.41，继续保留原保护作为对照。不能从总体成绩推断隐藏集具体哪类退步。
- 新独立校准融合代理均值18.74%→23.47%，但收益偏向空房，1人召回下降，3/4人召回弱。它不是已证明超过平台0.47的模型，也不是实际0.47逐类表现。
- 老结构里已有LagRelations相关矩阵支路，不能把再次添加协方差矩阵称作全新方向。已有静态路使用MixStyle，后续若增加风格扰动，必须对照已有机制，不能重复命名为创新。

## 优先实验A：保留已有能力，训练小型残差适配器

使用原结构及已获验证的权重初始化，在各路表示后增加小型残差适配器，初始输出为零。第一阶段冻结主干，只学习适配器和读出；确有收益后才单独比较解冻最后一层。与从头重训、只微调原读出形成固定对照，不同时改结构、损失、校准和融合。

原0.47作为教师，保留真实人数监督，并以较小的蒸馏约束保留原模型的概率信息。蒸馏不是提升保证，原教师会犯错，不能让学生仅复制教师。时间反转与少量接收通道变换同时用于训练一致性，仍保留原视角监督；一致性必须作为有/无的消融，不强制所有变换等权。

严格限制：外层留房间实验的教师也必须仅见训练侧记录；不能用实际全数据0.47指导外层学生后声称验证独立。实际0.47只能用于最后全数据训练，或明确标为含全数据教师的非独立诊断。新权重、新校准均不继承0.47成绩。

先做固定配方的读出微调、残差适配器、适配器加一致性三个对照。开发证据不稳定则不继续多种子筛选或导出。

## 结构实验B：训练时处理天线编号，而不在输出端强行平均

候选补充模块：各接收通道共享一个时频编码器；各有向天线对共享一个关系编码器；最后使用对编号对称的聚合形成表示，与原四路线表示作小幅残差结合。成对相位输入要随方向正确处理，不能只交换幅度而保留错误相位含义。

这是对原模型的表示层修改：模型训练时就学习如何利用不同接收通道。与0.41的区别是，后者不改变训练，只把已有顺序敏感模型的多个输出直接平均。共享结构是否更好仍需验证，不能因为人数标签对重编号不变就宣称它一定无损。

保留绝对扰动强度；同时比较相对幅度、天线间关系与时间变化，避免归一化后把计数信号一起消掉。协方差/相关量仅作候选特征，不能把矩阵秩、峰数或独立成分数直接等同于人数。不把中间通道命名为真实的静止/慢走/快走检测器，因为没有相应监督标签。

## 训练实验C：利用U数据学习信号表示

在规则允许的U数据上先比较掩码特征恢复或时间/接收视角一致性，保持人数分类由有标签数据监督；先不把教师对U的预测直接当成真实人数。设置有/无U对照，记录U范围、划分与任何目标域接触。不要强制U类别均匀或靠伪标签数量证明覆盖了3/4人。

房间与类别强相关，不能直接套全局域对抗、强行去掉所有房间信息。若比较同人数跨房间的表示约束，只对训练侧实际有同类覆盖的房间使用；外层折缺少高人数的跨房间支持时必须报告，而不是补造样本。

## 验证与提交顺序

1. 同房间留整条记录用于检查基本计数能力；整房间留出用于检查迁移风险。两者都先隔离源记录再切窗，分别报告，不能合并成一个“测试准确率”。同房间结果更乐观，留房间结果在本数据上同时留布局，都不能替代隐藏平台。
2. 每个候选的校准只使用训练侧独立记录/交叉拟合预测。报告无校准、该模型自身校准及既有偏置的敏感性，不能靠外层标签挑偏置。
3. 逐类、逐房间、源记录级纠正/改错与预测分布一同报告。以少量种子检查敏感性。原先要求每类一点不降是保守筛选规则；以后若考虑改变权衡，应在新一轮开始前定义并说明，不能看完结果临时放宽。
4. 首选提交证据最充分的一个候选，并保留四视角0.47原文件。平台仍未知，不能承诺下一次达到0.54，也不能给各模块分配虚构的加分预算。导出后重新检查单文件<100,000,000字节、CPU均值<0.7秒、内存限制与接口。

## 论文依据及适用边界

- [DASECount](https://arxiv.org/html/2211.10040)：将幅度/相位表示学习、蒸馏与目标域分类分开，支持保留已有表示再适配的研究方向；其高准确率依赖目标域每类少量有标签样本，我们没有这些隐藏标签，不能直接移用成绩或完整流程。
- [WiSR](https://doi.org/10.1109/TMC.2023.3292229)：研究无线感知的风格随机化和域泛化；实验是手势任务，不能证明人数计数同样有效，也不消除我们类别/房间混杂的问题。
- [People Counting by Dense WiFi MIMO Networks](https://www.mdpi.com/1424-8220/19/16/3450)：研究空间/频率统计、相关性等计数特征，支持超越单纯波动强度的候选表示；其多链路布置与本题1Tx/3Rx不同，不能照搬实验准确率。
