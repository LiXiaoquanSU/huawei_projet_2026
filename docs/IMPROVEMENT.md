# 后续改进原则

两份0.37之后的新核查与有限实验方案见 [最新改进分析](NEXT_IMPROVEMENTS_AFTER_SEED42_037.md)：优先诊断固定融合，再测试动态路线分段汇总；两教师蒸馏以折外互补性为前提。包含记录级类别分布、与旧实验的区别及论文适用边界，尚未执行新训练。

当前最佳仍为0.37，原宽度随机重训seed42本次达到0.37，与历史版并列。天线重排＋无标签一致性版0.33，此前全量数据EMA教师版0.35、SAM0.32、频率集合0.25；没有已评测的新配方超过基准。当前先整理与保留结果，不继续扩展训练。

若恢复实验，优先少量有解释力的对照：

1. **先改善验证依据。** 固定记录和整房间划分，记录逐类召回与多个种子的波动。现有开发集已经反复使用，不能重称为独立盲测。需要新增独立采集记录或平台更细错误信息时，明确其当前尚未取得。
2. **拆开0.35实验的因素。** 已保存的纯监督微调、学生、EMA教师可帮助对照；前两者平台未知。先分离继续训练、U损失与EMA的作用，再扩大搜索，不能把0.35单独归咎于无标签数据。
3. **保留0.37配方作成对基准。** 结构与训练设置分开改变，固定数据范围、更新预算和种子。比较的是完整配方，不把本地某个峰值当已确认升级。
4. **检查无标签目标是否可靠。** 高置信软目标可能强化原模型偏差，信号重建／相关性目标也未必对应人数。对接受率、预测类别分布和误差做核对；需要真值时不能用模型预测冒充。
5. **外部数据先做适配核对。** 官方U在硬件上更匹配；其他CSI数据需要检查频点、天线相位、采样率、人数标签和使用条件。直接复制天线或插值频点不能生成真实采集关系。

0.33反馈新增两条约束：本轮SU本地34.1%原本就低于S-only的35.0%，仍为“用全U”优先选择SU，推荐依据不充分；以后不把数据用量当作收益证据。天线重排、无增强继续训练、再加U应在相同更新预算下比较，并监测恒定预测也能满足一致性的退化解。平台0.33不能单独归因于天线、U、继续训练或精度修复中的某一项。

暂不优先继续盲目加深加宽、延长同一训练配方或大规模搜索融合比例。0.37是已验证最佳组合，仍不能证明结构或方法已经达到上限。
