# 从 0.37 继续改进的空间

## 结论

最佳版 0.37，SAM 0.32，下降 5 个百分点。两者结构和 5 轮预算相同，改动主要在训练优化；结果只证明这次 SAM 配方没有改善平台表现，不证明所有 SAM 配方都无效。只有总分，不能确认具体误判类别，也不能把下降归因于此前的下载错误或数值边界差异。

当前暂停训练。下面是后续值得验证的方向，不是已实现的功能或达到 0.5 的承诺。

## 优先级

| 优先级 | 方向 | 依据与下一次对照 |
|---|---|---|
| 1 | 固定更可靠的验证方法 | SAM 房间均值升、记录留出与平台降，单一划分会误导。同时报告按房间、整条采集记录留出的结果；固定划分、训练预算和少量随机种子，比较均值与波动，避免挑最好一次。旧数据已反复使用，不能重新称为独立测试集。 |
| 2 | 改进表示，减少环境捷径 | 四路线中静态频谱可能同时包含人数和房间信息；归一化又可能丢掉有效扰动强度。这是待检验假设。保留 0.37 结构，分别对照静态、动态、相位、强度统计的贡献；先确定哪些特征跨房间稳定，再替换分支。 |
| 3 | 利用无标签数据预训练 | 有标签数据只有 48 条，960 个窗口并不等于 960 个独立环境。可研究幅度／相位联合掩码重建，再微调人数头；严格记录预训练数据来源，避免验证记录混入。未知房间重叠无法排除时，不能把结果称为严格跨域验证。 |
| 4 | 改善真实时间与多尺度运动表示 | 当前部分运算按帧聚合。可对照按真实 ATI 时间构造短／长时间尺度，或在处理不规则采样与缺失后提取频谱变化；直接对不规则帧序列做 FFT 不能当作可靠物理频率。先单独替换时间路线，不同时加宽整个网络。 |
| 5 | 检查人数子任务与最终融合 | 分别评估有／无人、逐级人数、五分类和最终输出的逐类召回，判断错误来自哪个环节。本地误判不等于平台同样误判，不能仅凭总分修改某个人数的偏置。 |

自监督方向可参考 [CIG-MAE](https://arxiv.org/abs/2512.04723)：用幅度／相位双流做掩码重建和跨模态约束。该论文研究的是 WiFi 动作识别，其结果不能直接当作本项目人数识别的效果。这里建议借鉴学习任务，不照搬其准确率或全部结构。

## 暂不优先的做法

继续加深加宽、单纯增加训练轮数、大量搜索融合比例和只换优化器，都缺乏本项目的稳定正面证据。82 MB 已有足够容量，但还没有证据表明接近 100 MB 就会更准确。优先解决数据泛化与信号表示，保持每次改动可解释。

若恢复实验，建议顺序：锁定 0.37 权重和验证协议 → 分支贡献对照 → 一种自监督或时间表示改动 → 验证一致后做一次全量训练与官方评测。格式、运行时间及数值一致性仍需检查，但不能用它们代替准确率验证。
