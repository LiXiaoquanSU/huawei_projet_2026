# WiFi人数识别：全项目经验与0.60路线复盘

截至2026-11-07。平台分数以用户反馈为依据；本地开发验证、训练拟合、无标签预测分布严格分开。当前已测最佳仍为0.54；没有已验证超过0.60的模型。本次是复盘，没有启动新训练。

## 1. 当前判断

最可靠的资产是原0.37权重及其054推理流程，不是某个更大或本地某次得分更高的新结构。0.54的成功支持“已有表示有价值，如何校准和组合判断很重要”。最近实验同时说明：只在输出层继续修正，通常也补不上所有错误。应分别研究已有证据的错误使用和缺乏可迁移人数证据，不能假定存在一个遗漏因素可以解释剩下全部错误。

平台0.54→0.60需要净增加约6个百分点；若不破坏任何正确判断，相当于修复约13%的原错误。若新增专家纠正10个百分点但破坏5个百分点，只净增5个百分点，仍不够。此为算术目标，不是已知隐藏测试错误分布。

## 3. 0.54模型的真实链条

原始600帧CSI及间隔 → 固定幅度/相位/时间预处理 → 原037的四路线网络与权重 → Udirect偏置后的视角分数 → 类别条件选择 → 最终1人偏置。

四路线用于保留稳定状态、变化、通道关系和时间信息。它们是联合学习的判别特征，不是四个已有语义真值的检测器。

设v0为原通道正向，v45为原通道正反时间融合，F12为六种Rx排列×正反时间融合：

1. v0最高类别为1：使用v0。
2. 否则v45最高类别为0或2：使用v45。
3. 其余使用F12。
4. 最后加[0,0.35,0,0,0]。

融合为log(mean(exp(scores)))；不是logits算术平均，也不能称为先对每个已偏置视角做softmax再平均。偏置同时影响类别比较和路由，不是独立可随意叠加的组件。

实测主线：037→042→044（校准）；044→045→047（视角及规则）；047→048→049（条件保留及最终偏置）；049→054（保留规则下将fallback从4视角扩大至12视角）。它不是040融合模型继续训练的产物。

054的优势：原权重可用、表征多路、变换有互补、避免无差别融合。局限：保护规则按预测类别而非已验证可靠性判断；偏置依赖分布假设；12视角共享一个骨干，会共享错误；没有恢复独立人体，也没有解决活动/环境混淆。

## 4. 训练和验证方面学到的经验

- 48条标注记录是独立数据量的关键。960窗口或更密切窗不能被视作同数量独立场景。
- 2—4人主要只在a1/c1；0/1人与其他房间高度关联。新模型容易学到背景→人数，静态分支也不能因此全部删除，因为真实人数信息可能混在背景响应中。
- 管理员说标注与测试同分布、日常活动、无紧邻门外行人；U环境更广且可有门外经过者。不能把全部U当作同分布人数伪标签，也不能把每个U房间强制均匀。
- 原配方种子复现差异很大。无标签预测较均匀不证明准确；高判0比例也不证明错，因为没有U真值。
- 选中很早的训练轮次、源校准改善而目标记录不改善，反复出现。每类少量校准记录可能不足以稳定选轮；这是待检验原因，不是已证实解释。
- 整记录验证和留房间压力测试回答不同问题，两者都已反复使用，不能挑较高那个当真实成功率。学习好的训练拟合率不能替代泛化。
- 本地054代理不是实际054模型：它用排除目标房间后重训的权重。其278/880不能解读为实际054在隐藏平台的准确率。
- 代理602个错误中389个全部12视角均错，说明只选择一个已有视角无法修复这批错误；不是所有融合的上限，更不是隐藏测试的错误分布。
- 接口、大小、速度通过只证明能运行。推荐过平台025大版的教训是：不能以“有现成ONNX”代替有效性依据。

## 5. 冲击0.60的优先路线

### A. 先让候选评估更可信

外层按完整记录/房间留出；训练阶段选择和校准放在源数据内部，做多个整记录划分，避免一条校准记录决定训练轮数。预先固定预算、候选与筛选标准，多个种子复核。新的划分不自动成为盲测；真正新增独立采集/经规则允许且兼容的标注场景更有价值。

必须同时报告：整体正确率、类别平均召回、各房间/各记录表现、纠正数与破坏数、完整混淆矩阵。训练样本、校准样本与验证样本不得共享原始记录。不要用已见全部48条记录的054权重随机留出这些窗口来制造高分验证。

### B. 先审计互补性，再决定是否增加专家

原事件/跨注意力/上下文结构曾039、组合040，是与原037权重不同的表示来源；它们是否能补054目前未知。现有三份并列054也可能有不同错误，但同分不等于互补。

对候选A、参考B，在合规留出预测上统计A纠正B与A破坏B，逐类/逐房间分解；先判断是否有足够可用空间，再训练选择器或组合。真值决定的理想联合正确率只用于诊断，不能当可实现结果。实际全量旧权重在48条已见记录上的互补只能作训练诊断，不能证明泛化。

若没有稳定互补，停止做门控或融合。若有，再研究能从输入证据判断何时使用专家的规则，并保留同容量无新增信息控制。之前多种门控/纠错器已经失败，因此这条路线必须先获得新的互补证据，而不是换个名字再做。

### C. 结构改进应有明确的信息增益假设

保留054所体现的状态、动态、相位关系、时间和强度信息。新结构必须说明它额外保留了什么关系，以及为何该关系可能跨记录稳定。不能仅靠更多分支、参数、潜变量名称或辅助任务准确率论证。同步很高、人数排序很高都不是人数分类正确率。

当前优先考虑对已有不同表征的互补审计与源侧选轮稳定性，不优先重新扩大频谱、房间偏置或通用微调。若后续发现错误集中在某种有证据支持的信号条件，再建立相应专家；不能现在就断定必须添加静止/慢动/快动三个人体检测分支。

### D. 校准仍保留，但不再大规模盲搜

校准和保护确实有平台收益，应保留基线。进一步改变时，一次只改一个因素；检查是否仅在某房间/某类上转移错误。每房间均匀人数、U与测试一致等假设不能默认成立。最近偏置/双头/局部更新最高仍在053—054，不足以支持仅靠偏置必达060。

## 6. 当前决定

目前没有证据证明某个新模型可超过0.60；真实平台最好仍0.54。推荐的下一项工作是“源侧重复整记录选轮＋不同表征的互补审计”，结果决定后续是否训练新专家。尚未执行这项新研究，也没有把本次总结当作新模型结果。
