# 项目结论（最终整理：2026-11-13）

最终选择：根目录model.onnx，原版G′，已报告平台0.54；目标0.60未达到，私有测试成绩未知。

## 成功经验

1. 原0.37四路线权重是高分主线的基础。类别偏置、多视角和保护规则使其逐步达到0.54；不是扩大模型或重新训练取得了这段提升。
2. 保留静态幅度、动态变化、相位与时间的互补信息。删除看似房间指纹的信息可能同时删掉人数信息。
3. 对输入变换、缓存精度、随机流和ONNX部署做逐项核验，避免把实现差别当成科学结论。

## 失败经验与边界

- 扩容、更多随机种子、外部数据、重叠窗口、蒸馏和新结构均没有形成可靠的0.54以上平台收益；不意味着所有这些方法理论上无效。
- 同一记录切成更多窗口不会增加独立采集环境。训练内高准确率不能代替记录隔离验证。
- 多模型意见不同不代表错误互补；无标签预测一致或均衡也不代表正确。
- 2—4人仅覆盖两个有标签房间，活动强度与人数的关系并不跨房间单调。不能把运动、静止或房间面积当作已有中间监督标签。
- 测试集样本量和房间组成未确认。不能从上传耗时确定样本量，也不能把小分差直接称为随机噪声。

## 最后完成的实验

24次神经训练、6次线性探针：取消专家独立损失两种子各仅增加1/960；接收通道排序一种子+5/960、另一种子−78/960；同人数MixStyle452/960，对照455/960。没有产生新提交推荐。详见[阶段结论](RESEARCH_STATUS_20261111.md)。
