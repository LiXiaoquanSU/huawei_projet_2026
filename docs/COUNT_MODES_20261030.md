# 每个人数的多模式假设（2026-10-30）

前轮真实时间频谱在留房间验证失败，因此本轮检验另一假设：同人数可能对应不同的信号状态，单中心类别读出是否限制表现。冻结各折源训练的早期纹理骨干1664维特征；共同128维非线性映射后归一化，与每类1或4个可学习中心做余弦相似度、温度0.1的logsumexp融合。中心只代表潜在信号模式，不是受监督动作或独立人体。

3折×2模式数×2种子=12组，60轮/组，共720轮小型读出训练。仅源训练数据拟合标准化、映射与中心；仅源校准均衡NLL选轮；固定60轮预测保留。四中心额外1920个参数；两种子只改变读出，不重训骨干。开发折反复使用，不能代替独立盲测。

## 完成后的判断

单中心两种子432/960、410/960；四中心421/960、481/960。四中心相对单中心在种子42下降、2026增加；两个区间均包含零，固定末轮两种子均轻微下降。不能挑2026这一组宣称多状态已被学到，亦未超过此前497/960读出实验。该测试冻结骨干，只否定当前读出设置的稳定收益，不否定所有端到端多模式网络。

本次两轮研究都没有达到0.6，不增加新的待提交推荐。后续应优先做能区分原因的实验：将时间频谱作为与静态纹理并行的独立证据，而不是替换原输入，并保留同容量置零控制；只有在多种子、整记录以及留房间对照都有可复现收益后，才进行全数据训练与提交导出。不要在反复使用的单个开发分数上搜索到60%便当作目标达成。此后续实验尚未执行。
