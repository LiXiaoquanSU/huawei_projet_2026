## 研究结论

冻结骨干源选496/960，相对原479/960净增17窗，95%区间为−1.56至+6.04个百分点，不能认定稳定收益。改善仅在record0；record1/2选回原模型。按类别，3人正确19→44，但4人66→59、2人66→65、0人166→166、1人162→162。这更像已有证据的决策边界重新分配，没有证实获得新的可迁移信息。

约束方案确实降低训练特征漂移，但源选470/960低于原版；因此“减少漂移就能提高人数识别”的充分性假设不成立。固定8轮joint/frozen/anchored分别478/481/484，匹配差值区间均包含零。停止把该路线当作已验证突破，不输出声称更优的提交模型。

后续结构假设：检查当前全局均值/标准差池化是否丢失少量局部证据。比较在相同局部纹理编码器上使用分布池化（多个学习原型的软分配统计）与现有均值/标准差，先冻结同一骨干，限制新增参数，保留简单池化对照；原型只解释为信号模式，不能命名为独立人体。独立房间压力测试和新增种子复核应在任何提交推荐之前完成。这个方案尚未运行，也不保证有效。
