# 2026-11-08 后续实验结果

ordinal75平台0.47已登记并撤销推荐。已测最佳保持0.54。新增12次神经网络训练（102轮）、9次线性探针；未找到有充分提交依据的新模型，目标0.60未完成。

## 训练执行流程对照

原037结构，seed42、5轮、相同数据划分和损失。近期重置随机流的对照422/960（145、109、168）。本轮不重置为427/960（134、137、156），恢复原生DataLoader/采样器为445/960（137、131、177）。后者第一折退步，另外两折提高；不能当作稳定、跨种子的改进。

对照两种采样器的3折×5轮×640次抽样，仅1个索引不同；前两折全部相同。因此大部分差异不能归因于抽到了不同训练样本。DataLoader消耗CPU随机状态会影响MixStyle等操作的随机流，整体训练路径仍会变化。本轮不是完整复现原始037历史环境。

## 原始CSI联合幅相对照

受[FarSense](https://arxiv.org/abs/1907.03994)的CSI比值思路启发，构造有界坐标[2Re(hi·conj(hj)),2Im(hi·conj(hj)),|hi|²−|hj|²]/(|hi|²+|hj|²)，与仅相对相位对照。FarSense研究呼吸感知，本项目没有复现其呼吸算法，也没有把论文效果外推成人数识别成绩。新表示在有效载波、共享乘性扰动条件下抵消共同增益/相位；本地数值扰动检查通过，现实噪声和有效性阈值仍会影响效果。

先做固定均值/标准差/差分统计探针，再做同容量共享天线对编码器，保留32频率×150时间点的轨迹。相位对照补零到相同通道数，两组均12轮、相同seed和采样预算。摘要归一化只在源记录拟合。

## 表征依赖诊断

static_only将每条通道的时间轨迹替换为其时间均值；dynamic_only减去该均值。两者保留原17维摘要，所以不是完整消除全部静态或动态信息。它们是输入干预，不是实际分布下的独立测试，不能据此认定因果机制。

## 决定

联合幅相网络仅保留时间均值时，945/960个预测不变（改变15个），正确数382/960，正常输入为381/960；仅保留去均值变化后为201/960。这支持“当前网络主要依赖静态输入部分及保留摘要”的解释，而非证明它识别了房间身份。下一步若继续这条路线，必须先检验动态部分在同房间不同人数之间是否提供可迁移增量；不能把训练拟合提高或分支命名当作动态证据已经被利用。

不继续微调ordinal75比例，不导出固定路径反事实版本。联合幅相的数值抗干扰性质没有转化为本次人数泛化收益，暂不扩大该表示的参数量或将它接入054。原生训练流程保留作以后复现实验的明确控制，但445/960不足以证明能超过平台054。
以后提交应要求更强的机制证据和跨设置稳定性，不能再把旧代理净增几个窗口作为主要推荐理由。本轮各表都是已复用开发数据，不能宣布任何方案已达到060。
