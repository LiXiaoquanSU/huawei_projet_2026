# 时间细节与相位相干度对照：2026-10-27

本轮从48条标注记录提取全部960个非重叠窗口的新特征，完成84次逻辑回归拟合。没有训练新神经主干，没有导出提交模型。平台最佳仍0.54。

## 特征假设

时间分支保留逐帧变化与4帧内残差的相对能量：600帧、3接收通道，先按32子载波池化，再统计每频组；相位分支保留每对天线的复相位平均模长、瞬时相干度平均和时间离散程度。三个接收通道/天线对用均值与标准差对称池化。时间特征128维，相位192维；基础摘要13维。

相位特征不保留绝对相位角，合成数据已验证对固定通道相位偏移、通道排列、时间反转的不变性，以及零输入数值有限。该检查不证明真实环境下鲁棒，也不能把相干度直接解释成人数。时间特征使用帧索引，不是精确非均匀采样时间重建。

## 验证与选择

四个旧留房间开发折，训练和校准排除未知房间；另建三个按完整记录分组、人数分层的折，覆盖全部48条记录。后一种方式未保证所有房间都在训练中，尤其单记录房间可能整体落入测试，因此应称整记录留出，不称严格同房间验证。测试记录绝不进入训练/校准。每个源集合留出每类一整条记录校准；标准化只拟合源训练。

四组使用完全相同划分、加权采样等价的类别×房间样本权重和逻辑回归；C取0.01、0.1、1，仅按源校准类别均衡交叉熵选择。共7折×4组×3档=84次拟合。各组特征维数不同，结果不是严格相同容量神经网络消融。原平台权重未参与分类器训练和整记录验证。

## 本轮结论与后续

本次两类细节共同加入后，整记录267→388/960（27.81%→40.42%），但整房间198→61/880（22.50%→6.93%）。同一种简单分类器在两个协议下给出相反结论，且整记录改善集中在record0和record2，record1没有净提升。它符合环境依赖线索在新房间失效的解释，但也可能涉及正则、样本覆盖和模型容量差异，不能凭这一项实验断定物理原因。

不导出这套特征分类器供平台提交，也不据此断言细节无用。后续应检验：固定原骨干，新增零初始化、受限幅度的细节读出；同时保留仅原骨干及同容量对照，使用两套验证协议。训练时只用源记录选择权重，优先检查跨房间损失是否可以避免，而不是只优化整记录分数。原054全数据权重不能用于冒充留出训练的骨干。

两套验证的排序冲突是当前需要解决的问题。管理员说有标签与测试同分布，不足以确定哪种协议单独代表平台；应结合官方房间划分说明和历史平台表现判断，不应根据本轮哪个分数好就挑哪个。
