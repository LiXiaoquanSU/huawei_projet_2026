# 跨房间的0人、4人失效审计与独立空房分支

本轮完成64次轻量分类器拟合：三类输入×四档正则×四个留房间折，共48次五分类；另16次二分类。没有重新训练神经主干，没有获得新平台分数。最佳已测仍0.54，本轮不产生推荐提交模型。

## 数据与边界

沿用a1、c1、g1、e1四个留房间开发折，共880个窗口。训练、校准、测试按整条记录隔离。每折只用源房间的五条校准记录选择正则强度与融合权重，不以目标房间标签选择参数。这里的“054代理”是排除目标房间后重训的旧结构，不是平台0.54权重。开发折已反复使用，结果不能当成新的盲测，也不等于平台成绩。

## 学不会，还是换房间失效？两种情况同时存在

新结构在留a1折：训练侧4人60/60正确，源校准12/20正确，目标房间0/60。留c1折：训练侧40/40，校准20/20，目标0/80。对应目标4人类别平均排名约4.97和5.00（第一名最好）。这不是轻微边界偏差；它符合明显的房间相关特征失效，但还不足以证明具体物理原因。

留g1折选中第1轮：训练侧0人0/60、4人0/120，说明检查点选择同时存在训练不足。不能把所有失败都解释为过拟合。每类仅一条校准记录很脆弱；例如b1唯一的空房记录被留作校准后，训练侧完全没有b1。

高人数只出现在a1、c1。留掉其中一个房间，训练侧2—4人只来自另一个房间。即使窗口很多，模型也没有获得多个独立房间中的高人数对照。

## 独立空房分支：实际做了什么、为何暂不采用

使用17维信号统计量（六种接收通道排列和两个时间方向平均），训练逻辑回归判断空房/有人。训练权重按原五个人数类别与房间均衡；只用源训练数据拟合标准化。正则C从0.01、0.1、1、10按源校准交叉熵选择。

保持原模型1—4人的相对概率不变，仅将空房概率与新分支按0、0.25、0.5、0.75、1融合。融合强度也只按源校准交叉熵选择，包含不启用分支的选项。该校准集被复用，不应将校准改善作为独立泛化证据。

- 旧代理：278→244/880（31.59%→27.73%）。
- 新结构联合概率：300→258/880（34.09%→29.32%）。
- 在g1，空房140个全部找回，但有人200个全部错判为空房。这是类别间交换错误，而不是可靠进步。

目前证据不支持直接给提交模型叠加这个空房分支。也没有依据将其接到实际054权重上宣称提升；本轮没有这样导出。

## 下一步的研究选择

1. **先修正选检查点的依据。** 保留留房间评估，同时加入多个整记录校准划分的稳定性检查，逐类报告源训练与校准召回。训练充分程度和跨房间泛化分开判断，避免凭单条记录选到未学会所有类别的权重。不能拿目标房间最佳轮数反向选模型。
2. **结构侧优先研究相对变化与空间协同。** 将静态背景与动态残差分开，比较跨天线相关、频率/时间协方差的归一化谱等描述，而不是继续强化绝对强度阈值。它们是否能区分静止人员仍须实测；协方差秩也不能直接当人数。
3. **验证要求是减少净错误。** 空房召回提高必须同时检查有人误杀；4人提高必须同时检查2/3人误判。加入同房间整记录留出，只作为区分训练能力与跨房间能力的第二条评估，不替代留房间测试。
4. **暂不扩大偏置扫描。** 当前4人排名接近最后，单纯抬高该类分数很容易把其他类别推错。保留平台054作为提交基准，下一结构只有获得可解释且跨折稳定的收益才考虑替换。
