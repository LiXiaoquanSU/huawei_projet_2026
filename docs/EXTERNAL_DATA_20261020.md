# 外部数据补充核查：优先研究 Wi‑Fi 6 的同类采集

后续更新：2026-10-21已下载0—4人MAT、完成清洗和单天线迁移对照，见[新报告](MOTION_EXTERNAL_20261021.md)。下文“未下载／未混入”描述2026-10-20当时状态；当前外部数据未混入官方验证分母，本次迁移配方也未优于基准。

本轮额外找到比 WiCount 更匹配的候选：[Tonini 等人的 802.11ax 人体感知数据](https://zenodo.org/records/17225694)。已下载作者 README，保存在 `checks/review_20261020/external_zenodo_README.txt`；未下载其约10.5GB的全部采集，未把它混入本次官方数据模型。

作者[采集论文](https://opendl.ifip-tc6.org/db/conf/wons/wons2026/1571217424.pdf)的 Table I 和方法部分表明：数据包含80MHz、人数标签与部分三接收天线采集，某些记录为12000帧、5ms间隔，与题目有接近之处。但表中三、四人数采集使用单接收天线配置；不能把所有0–4类都视为完整三天线数据。因此，它值得进一步转换验证，尚不是可直接拼接的额外完整监督集。

README说明复数CSI以MAT保存，原PCAP也提供；多天线分别保存为core1/core3/core4文件。下一步应先核对变量形状、1024子载波索引顺序、时间戳及帧序号，证明三个文件能够逐帧配对，再提取匹配窗口。不能简单把三份文件按行号对齐，也不能把单天线复制三次后当成真实三接收天线测量。

建议的受控试验：

1. 先以少量原始数据验证三天线同步与频率表示，确认采样间隔来自真实时间戳，而非用名义5ms覆盖丢包。
2. 对匹配的多天线记录，优先开展自监督预训练或低权重辅助监督；保留完整人数标签覆盖的官方训练作为最终微调，避免额外0–2类数据进一步挤压3、4人的学习。
3. 单天线3、4人记录只能尝试单天线幅度编码器预训练，再迁移共享特征；需要独立消融，不把它视作本题完整输入。
4. 按采集日期/设备位置划分外部训练与外部检查；官方仍按源房间、目标无标签支持、测试记录隔离。核对来源与官方数据是否重合，防止重复记录污染验证；不用外部文件名推断官方无标签或隐藏测试的真值。
5. 作者README给出CC BY-SA 4.0；保留出处并核对竞赛对外部数据的具体规定后，再将其纳入正式提交训练。

与此前候选比较：WiCount单天线52子载波且只有0–3人；EHUNAM的多接收设备不等同同一设备的三根相干天线；80MHz的802.11ac数据也不等同Wi‑Fi 6频率采样。Exposing the CSI虽为Wi‑Fi 6，却为160MHz/4天线及活动任务。以上资源可支持专门的迁移研究，但不能靠补零、插值或复制天线消除设备差异。

本次最终模型使用老师给的48条有标签与150条无标签记录。外部候选的发现不构成本次模型已经受益的证据，也不证明与老师隐藏测试同分布。
