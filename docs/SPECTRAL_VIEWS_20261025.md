# 0.51回报后的频谱与分层融合复盘

当前平台最佳仍为0.54。原始证据仲裁器实际平台0.51，已记录，停止推荐。本轮24组对照全部未通过预先设定的候选门槛，没有新增推荐ONNX，也没有上传平台。

## 对0.51的修正认识

上轮开发集278→298/880，其中g1贡献20窗，a1−1、c1不变、e1+1。实际原0.37底座的训练来源数据676→647/960，救回1窗，改坏30窗。
这30窗具体为：2→3共18窗、1→0共7窗、0→1共4窗、2→1共1窗。它说明仲裁器在可见数据上改坏了已学会的判断；不能据此断言平台隐藏错题也有相同分布。

上一轮允许来源正确数下降29窗的发布标准过宽。跨房间开发增益集中一个房间，也不足以证明能迁移到原权重或新房间。平台0.51证实该候选没有超过0.54，但单个总分不能单独证明下降由哪一类错误引起。

## 本轮控制与门槛

- 底座使用相同原0.37权重，按原044精度存储方式核对；原054偏置、原视角1人优先、双时间0/2保护均为对照。
- 使用真实054 ONNX预处理缓存。四个留房间代理使用历史各自排除该房间的底座；实际模型使用原权重。
- 评估为a1 240窗、c1 240窗、g1 340窗、e1 60窗，总880；来源960窗不是独立测试。
- 候选须跨房间净增至少9窗，至少2个房间改善，任何房间净损失不超过2窗；来源不得下降；固定房间内整记录bootstrap的95%增益下界须大于0。
- 此门槛在首组评估之前写入D盘plan.json；后续两个实验家族均在各自评估前记录参数。四个房间已经多轮用于开发，属于探索性筛选，不能称盲测或将bootstrap视为跨新房间保证。
- 没有新增训练、外部数据或隐藏标签；本轮是固定权重推理结构对照。没有为了发布候选而降低门槛。

## 24组对照

|家族|数量|留房间净增范围 /880|来源净增范围 /960|结论|
|---|---:|---:|---:|---|
|频率翻转/平滑后参与fallback融合|4|−8～+3|−2～+18|未通过|
|分开融合有人/人数或低人数/高人数|12|−8～+1|0～+15|未通过|
|四个变换视角一致才纠正保护结果|8|−8～+1|−6～0|未通过|

频谱方案每次增加4个特征视角：原接收通道/反序接收通道×正向/反向时间。频率翻转同时反转128频率幅度特征和32频率相位特征；平滑是相邻频率1/4、1/2、1/4加权，端点复制。保持时间、间隔和原始全局统计特征不变，因此这是特征扰动假设，并非保证对应真实CSI物理变换。

分层方案在原有6个接收排列预测中，保留融合后的人数群概率质量，仅对群内人数条件概率重新平均或取几何共识。分界分别为0/1–4与0–1/2–4，融合比例0.25/0.5/1.0。不引入新类别偏置。

一致性方案要求四个新增视角都选择同一个相邻人数，并且其平均概率中候选相对原人数的赔率至少2:1；只允许修改原双时间0/2保护分支，原1人优先仍保留。比较仅空房和整个受保护分支、0.25/0.5两种混合比例。

## 得到什么、下一步如何改变

1. 平滑和分层融合能提高来源正确率，却不能稳定提高留房间正确率。来源提升不能直接当作网站提升。
2. 保留原保护几乎不动时，改进空间在这些实验中很小；解除保护又容易破坏2人判断。仅用视角一致性也没有解决这一矛盾。
3. 上轮的新种子OOF仲裁与最终原0.37底座之间存在迁移风险。应减少这类跨底座纠错器的自由度；本轮也不再继续放宽它的阈值。
4. 下一项值得验证的训练假设是：从已有效的原权重出发，小步训练特征提取部分，使同人数跨房间更接近，同时保留原预测作为约束，并检查是否损害少数人数类。它尚未执行，不承诺优于已有模型，也不把它称为本轮成果。
5. 真正检验训练方向应采用额外整记录验证与多底座一致性审计，明确哪些记录原权重已经训练过。来源数据不能重新命名为独立测试集；不能靠更多重叠窗口消除房间与人数的混杂。
