# 实际采样时间频谱实验（2026-10-30）

从48条原始CSI/ATI记录提取960个非重叠窗口；输入只使用单窗口。7个倍频频段0.5—64Hz，每段4个投影频率；梯形时间权重、去时间均值，幅度与相对相位谱能量分别归一化，按接收通道/天线对做对称均值与标准差。低频分辨率受约3秒窗口限制；频段能量不能解释为独立人数。

三个等维输入：实际时间600帧、等间隔600帧、实际时间4帧平均。后者高频可能混叠，是压缩对照，不是有效高频恢复。另有13维摘要基线。时间反转与零输入检查通过。

## 决策边界

这些反复使用的开发划分不是盲测。时间处理改善是否有效，应看actual与uniform匹配差异，不能只对比更弱摘要。若不能跨种子和房间支持该假设，则不追加扩大此结构。未导出新提交模型；平台最佳仍0.54。所有特征、权重和逐窗口预测保存于`D:/huawei2026-experiments/timed_spectrum_20261030/`。

## 完成后的判断

实际时间卷积版整记录为386/960与372/960，等间隔为373/960与373/960；留房间实际时间111/880与139/880，等间隔117/880与129/880。两个种子没有一致的实际时间收益，独立频谱分类无法支撑提交。频谱化丢弃时间顺序并压缩静态信息，因此此失败不能证明真实时间没有信息，也不能排除它作为联合模型的辅助输入。停止扩大独立频谱路线。
