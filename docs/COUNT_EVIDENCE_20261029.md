# 人数监督与静态相位证据：2026-10-29

本轮新增12组神经网络训练、240轮，18项记录级趋势诊断，以及126次静态相位轻量探针拟合。目标是合理可检验的识别链，0.6不是通过换指标或选择测试窗口凑出的数字。所有结果来自重复使用的开发划分，不等于平台成绩。

## 三个问题

1. 同房间人数递增是否有简单共同规律？a1与c1的运动能量、高时间频率比例与人数相关方向相反，不支持“人数更多→变化更强”的统一规则。只有11/12条对应记录，不能作因果结论。

2. 是否能通过人数语义监督，减少环境捷径？分别测试同房间跨记录顺序损失，以及同人数跨房间正配对/不同人数同房间负配对。两者各自只在原纹理版上增加一个训练目标，未混合。未知房间不当作可确认的跨房间正样本。

3. 是否缺少静态空间相位信息？原相位特征按时间去均值。新增原始CSI的相对相位频率曲率，消除理想整体/线性频率相位歧义，保留稳定相位形状。它也可能反映房间与硬件，不能预设为人体特有。
