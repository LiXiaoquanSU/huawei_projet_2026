2. 原始监督＋一致性、再加同类跨房间约束：没有解决上述部署目标错位。
3. 改用固定校正后的实际输出监督：得到局部收益；强适配的跨房间退步明显。
4. 实际输出监督＋一致性：选小残差0.25，不额外做概率混合。
5. 再加同人数0/1跨房间中心对齐或困难类别/房间组的平滑最大损失：没有稳定超过第4组，不推荐额外复杂度。
