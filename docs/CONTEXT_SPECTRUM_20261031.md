# 固定纹理骨干的上下文频谱修正（2026-10-31）

根据联合从零训练的对照结果，检验固定已有特征是否能避免训练漂移并利用频谱。使用每折源训练得到的早期纹理骨干，其1664维表征和五类概率保持不变；新增纹理128维映射、频谱128维编码和二者tanh逐元素乘积，再经小读出产生每类±0.5以内的logit修正。初始化为原模型等价。

三方案：product包含显式乘积；no_product将乘积槽置零但仍有两个分支，MLP仍可产生隐式交互；zero将频谱输入置零，保留相同分支和参数。3折×3方案×2种子，每组30轮，共18组540轮修正器训练。种子只重训修正器，骨干不变。允许源校准选回epoch0，固定30轮也报告。

## 完成后的判断

显式交互两种子471/960与449/960，置零475/960与488/960；两种子均未超过置零对照。无显式乘积404/960与439/960，说明交互形式影响学习，但不证明谱信号有额外贡献。固定末轮也未显示两种子一致收益。当前不扩大该修正器，不导出声称更优的提交模型。

结合独立频谱、从零联合纹理频谱、固定骨干的有界修正三种设置，目前均缺乏可复现收益。结论只适用于所用7频段/32频组、对称谱能量表示及训练设置，不是对所有频域方法的否定。后续优先级应从扩大频谱分支转到验证跨记录稳定的类别证据；需要用新的源侧划分/种子验证后，才进行任何提交推荐。重复开发集上偶然达到60%不应视为完成平台目标。
