用户2026-10-25反馈相关性统计辅助版平台0.49，提交编号未知。文件SHA256为`e86a2a17f324089d4c115d0dcec8ed5ab486247b21b615938e5596e5f6fed5e6`；侧记、registry、成绩CSV已更新，取消待提交状态。

与原最终1人偏置+0.35版并列0.49。继续以较简单的原版作首要对照，两份获分文件均逐字节保留。相同显示分数不能说明隐藏预测一样，也不能知道新模型究竟修复、破坏了哪些隐藏样本。没有置信区间、完整精度分数或逐样本输出，不能归因为“新分支完全没用”或确定的隐藏类别问题。

## 新复盘：改变范围仍很有限

入口`tools/analyze_after_correlation049.py`，完整结果`checks/after_correlation049_20261025.json`。本轮只做评分登记、已有输出分析和U的ATI/文件元数据审计，没有新增优化训练或ONNX导出。

相关性版在960窗中改变39窗，涉及17条记录，纠正29、改坏2，另外8窗是错误类别之间变化。主要改判包括18个4→3（13个纠正）、6个4→1、4个3→2；两次改坏都是原本正确的2→3。这些全部是参与原底座训练的源数据，不能推断隐藏集同样偏向过估。

原模型判0/1的511窗全部保留，其中仍有107错：94个真实1人判0、13个真实空房判1。它们占新版本245个源错误的43.7%。保护避免一部分退步，也使这一批输入不可能改善。

但不能直接取消保护。当前统计辅助头在源数据上的诊断：

| 拟开放方向 | 原错误中辅助支持纠正 | 原正确中辅助支持错误改判 |
|---|---:|---:|
| 0→1 | 23/94 | 7/206个正确空房 |
| 1→0 | 5/13 | 20/198个正确1人 |

这是辅助5类argmax的票数，不是已经验证的新提交规则，且辅助头见过这些标签。方向上只支持优先研究受控0→1，不支持同时打开1→0；即便0→1也须重新过未见房间的误报检查。94个漏报中92个来自g1，不能用这一个房间的局部收益定义通用人体检测器。

此前已有24次0/1读出/信号分支和32次成对证据训练，未获稳定迁移；双时间去偏置0→1平台也只到0.48。因此下一轮不能把同一个0/1末端分类器或阈值换名字重做。差异必须发生在信号表示及环境覆盖上。

`D:/huawei2026-data/unlabeled`中有150组CSI/ATI文件，全部ATI长度12000。按600帧非重叠切分可提供3000个候选自监督窗口，但不是3000个独立环境，尚未在本轮生成CSI特征缓存。

这是从文件名读取的分组，不是本轮独立核实的物理房间元数据。u1/v1合计102/150，直接等权抽窗会偏向这两个分组。采样应先平衡已知分组，再平衡记录；unknown按各自记录处理，不能当作同一个已知房间。

多数记录正间隔均值约5.15–5.18ms，少数h1记录到5.46ms；超过20ms的间隔比例通常约0.05%。这里没有明显数量级的采样率差异，暂不足以把瓶颈归因于大范围采样率失配。真实ATI仍须保留。这次没有审计全部U CSI数值、空载波或复数有效性，后续缓存前需要检查。

没有U人数标签；不能声称它补齐2–4人类别，也不能假设它与隐藏测试同一物理房间、人数均匀或仅有类别先验变化。

## 下一轮首选：源数据＋官方U的自监督表示训练

核心问题是让网络见到更多环境下信号变化的规律，而不将教师对U的猜测冒充真标签。

1. 保留原0.49及统计0.49作固定控制。先准备官方U按记录保存的特征缓存，记录原文件SHA、有效载波/复数/ATI检查及采样清单，大文件放D盘。
2. 同一600帧窗口构造正确Rx重编号和时间反转的两个视图。正对只来自同一窗口；不把同一U记录中的不同时间窗自动认定为同人数正对。不将其他窗口一概视为异人数负对。
3. 比较有标签监督＋多视图一致性，与加入防塌缩的自监督表示约束。可借鉴[VICReg](https://arxiv.org/abs/2105.04906)的视图不变性、维度方差及去冗余约束；论文原任务为图像，不证明本题有效。特征方差约束也不等于强迫0–4类人数均匀。
4. 以原权重初始化，真正更新相位/时间编码器后段，先保留静态编码及已有分类头；不是只在冻结特征末端再训一个小读出，也不重做已平台0.48的16,672参数适配器。自监督投影头训练时使用，部署时移除。需统计实际更新参数并验证未更新权重保持。
5. 真实标签监督始终保留，并轻度约束源样本输出漂移，防止丢掉现有计数能力。首轮固定已有推理校准及偏置，避免把同时改偏置的收益归给表示学习。若表示改善但尺度漂移，再单独做训练侧校准对照。

[WiCount-DASL机构摘要](https://research.polyu.edu.hk/en/publications/wicount-dasl-domain-adversarial-semi-supervised-learning-for-wi-f/)也把少标注、无标签数据与跨场景计数结合，并讨论伪标签可靠性。但本轮只核对摘要，不能称复现其完整方法；第一阶段不引入硬伪标签或全局域对抗。房间与人数混杂时，盲目消除所有域差异可能同时抹掉人数信息。

## 最小可归因实验顺序

| 组别 | 真标签监督 | 同窗口变换一致性 | 使用官方U | 后段编码器更新 |
|---|---|---|---|---|
| A 固定已评分对照 | 既有 | 既有推理增强 | 否 | 否 |
| B 同预算监督微调 | 是 | 否 | 否 | 是 |
| C 源数据自监督增强 | 是 | 是，带防塌缩 | 否 | 是 |
| D 加官方U | 是 | 是，带防塌缩 | 是 | 是 |

训练预算、初始化、更新层及源监督保持一致。先用已有四个整房间排除划分与两个种子检验方向；代理不能使用外层标签或外层CSI参与拟合，校准只用训练侧完整记录。若另做“外层输入当无标签”的迁移实验，必须单列为有目标域输入的实验，不能混作无目标域接触的泛化成绩。

主要比较D相对B/C，才能知道U是否提供额外信息；不能只拿D的源数据训练准确率与A比较。监控空房新增误报、1人召回、2/3/4退步、逐记录纠正/改坏、预测是否单类塌缩，同时报告最差房间。g1单独提高仍不足以认定成功。

## 后续0→1开放的前提

只有新表示在独立房间中改善0/1可分性，才增加一个受限0→1试验。保留原判1的输出，避免同时引入5救/20坏的反向改判风险。

同房间0/1对比监督只在真实同时存在两类的a1/e1/g1构造；c1无空房、b1无1人，不能编造配对。此类约束应作用于更新中的信号表示，与此前只在17参数现成证据上加成对排序不同；仍必须有不加该约束的对照。

校准按完整空房记录交叉拟合，报告记录层面的不确定性，避免把20个相邻窗当作20间独立房间，也不再凭单条空房最高分承诺未来误报率。老师部署时不要求额外空房参考，不使用房间文件名作为人数预测输入。
