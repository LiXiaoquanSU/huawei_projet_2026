# 局部分布池化机制实验（2026-10-30）

假设：局部纹理中的多种信号模式，可能在均值/标准差汇总时丢失。每折冻结同一份早期CNN，提取池化前局部256维特征，以固定正交投影降至32维；只在源训练记录中拟合标准化与8个局部模式原型。按频率位置统计软分配比例与残差，接简单五类分类器。原型是信号模式，不能解释为独立人体。

三折、四种输入、四个正则强度，共48次拟合。正则强度仅按源校准均衡NLL选择；所有预处理、原型及分类器只拟合源训练记录。标准化均值/方差控制与分布池化使用相同局部特征。旧1664维表征为另一基线。分布版特征维数更高，并非严格等容量；改善后还需容量控制。

## 决策

分布池化线性探针470/960，对局部矩统计455/960净增15窗，但整记录区间包含零；非线性分布版两个种子均未稳定优于旧表征。当前证据不足以支持扩大该结构或导出更优提交版。最高组合读出488/960（50.83%）仍低于此前早期倒数第二层线性读出497/960（51.77%）；这些比较均是重复开发数据，不能作为平台预测。

下一项待检验问题应移到编码器之前：固定缓存的归一化/频率与时间压缩是否限制了新结构。设计原始CSI的多分辨率输入，明确有效载波、实际时间间隔以及静态/动态信息保留方式，与相同骨干、同维数压缩控制比较。在该实验完成前不宣称瓶颈已被定位。新原始输入方案尚未实施。平台最佳仍0.54，0.6尚未达到。
