# 题目约束下的后续结构与训练方案

本轮实际实现的是保留0.37骨干的天线重排与无标签一致性；下面的架构是下一阶段的明确假设，尚未训练，不能标为有效模型。

## 首先修正验证，而不是追逐训练准确率

有标签记录的人数与房间强相关：2–4人的监督主要来自a1/c1，而另一些房间只有0、1人。网络即使训练准确率很高，也可能主要辨认房间。隐藏房间来自不同源域，随机切窗口会把同一记录的环境特征泄漏进验证。

继续使用整记录隔离，分别报告：没有目标支持的留房间测试，以及有独立目标无标签支持的测试。两者不混合。按房间平均准确率、五类召回、3/4人混淆和NLL共同检查，记录随机种子波动。重复看过的开发数据无法成为新的盲测；最终仍需平台反馈。

## 更有依据的新结构：天线节点与相位边

- 每根接收天线用**同一个编码器**处理幅度的时间—频率图，保留频率坐标，避免重演频率集合模型丢掉谱线位置的问题。
- 三对天线用共享边编码器处理相对相位与幅度比；交换天线时，明确处理相位差正弦项的符号，不能随意打乱六个相位通道。
- 用对节点编号不敏感的聚合得到整体表示。相位边与幅度节点共同交互，不只是对三次分类投票。这样可以从结构上保证编号不改变预测，而非依赖有限训练学会。
- 保留真实采样间隔和短/长时间尺度分支。局部卷积或TCN学习短时运动，较长注意力汇总整个600帧；LSTM可以作为同预算对照，但它的顺序建模能力不等同跨房间泛化能力。
- 保留0.37版的直接五分类与序数人数头，同时检查空房/非空房的独立召回；人数由多个阈值判断可解释，但不能假定所有房间的人数信号都单调增大。

共享单天线编码器还有一个数据优势：可先在真实单天线外部数据上预训练，再增加多天线关系分支。必须分别证明单天线迁移和关系分支的收益，不能复制天线创造相位关系。外部部分0–2人三天线数据也不能直接淹没官方少量3、4人监督。

## “房间、运动”能不能单独检测

可以学习慢变化的静态频谱表示和快变化的动态表示，给两类信息不同分支；0.37结构已经部分采用这种设计。但目前没有房间尺寸、人体轨迹或活动类别的真值，不能把中间层称为已检测到实际房间大小或人数运动。多个不同房间可能产生相似CSI，这是可辨识性问题。

可用不依赖人数真值的预训练任务，例如恢复被遮挡的真实频段、预测同一记录不同片段的共有成分、学习相位/幅度跨天线对应关系。评估预训练是否帮助人数任务，而非仅展示预训练损失下降。若把房间信息全部对抗删除，由于源数据的房间与人数耦合，也可能一起删除人数信息，因此不先把域对抗设为默认方案。

## 训练的下一步怎么比较

固定初始化、数据划分、计算预算，一次只改变一个因素：先比较无增强继续训练、天线增强、再加无标签约束；本轮冻结基线与微调的比较同时包含了额外训练预算，不能把全部差值归功于天线增强。再单独检查全量遍历与类别/房间平衡、不同无标签权重，以及预训练后微调。

平衡有放回采样有助于稀少人数/房间组合，却不保证三轮覆盖每个窗口；今后可用“每个源窗口一遍 + 额外平衡抽样”的配方，并给所有对照相同更新预算。本轮采用既定平衡采样，具体覆盖率另行审计，不把候选池大小当作实际遍历次数。

HMM适合带跨窗口状态转移信息的连续序列。题目单次只给一个人数恒定的600帧窗口，没有跨提交调用顺序保证，因此不能依赖跨调用状态；若只在窗口内建模，必须证明它比现有时序汇总更好。

每个候选先满足100MB、CPU 0.7秒、6GB内存的接口限制，再按独立记录验证选择一个；不能以更大的模型、较高训练准确率或论文原任务成绩作为提交理由。
