# 动态信息能否跨记录识别人：2026-11-08

本轮完成9次神经训练（108轮）和18次同房间线性探针。所有结果均来自复用的本地记录，不是平台隐藏测试。已测最佳仍0.54；ordinal75已测0.47，不再推荐。没有新增提交文件，0.60目标未完成。

## 一、匹配条件的三组网络

复用原始CSI的有界联合幅相轨迹，比较完整轨迹raw、每条轨迹时间均值static、去均值后按天线对共享RMS归一化dynamic。三个结构参数一致，17维额外摘要全部置零；固定seed42、12轮、同一优化器和采样预算；外层完整记录不参与训练或选轮。static/dynamic是信号分解，不是静止人/移动人的语义标签。

|输入|各折正确/320|正确/960|准确率|源拟合正确/1920|
|---|---|---:|---:|---:|
|raw|[84, 103, 180]|367|38.23%|1715|
|static|[91, 113, 171]|375|39.06%|1715|
|dynamic|[131, 110, 148]|389|40.52%|1872|

源拟合1920次来自三个模型各自640个训练窗口，同一原始记录重复出现，既不是独立样本数，也不是泛化成绩。
动态相对静态净增14/960，但按整记录、折内重采样的描述性95%差值区间为[-10.10%,+12.92%]。第一折提高40个，第二折下降3个，第三折下降23个；不是一致提升。区间不校正多轮研究选择偏差。

## 三、已知同房间的诊断

a1/c1只比较1—4人，g1只比较0/1；仅纳入每类至少两条记录的任务。各房间独立按完整记录二折，标准化只拟合源记录，逻辑回归固定C=0.01。房间与候选人数集合已知，任务比比赛五分类不同，不能用其中任一高分声称达到0.60。

|房间|信号|正确/总数|准确率|类别平均召回|

a1动态109/220，比静态93/220好；c1动态49/240，仍弱于四类均匀随机选择的25%期望准确率；g1动态190/340，但该子集全判人数较多的1人已有200/340。因此这里没有证据证明动态轨迹已稳定提供可迁移的人数信息。少量不同采集记录还可能包含布局、活动、设备状态差异，已知房间并不消除这些混杂。

## 结论与后续边界

去掉静态信息并归一化动态，确实改变了学到的表征，却没有带来可靠的人数泛化。既不能说动态信号没有人数信息，也不能假定静态信号都是噪声或应当删除。当前特征、模型、样本覆盖和优化仍可能不足。
下一步若重新建模，需保留静态占用信息，同时验证动态信息对具体人数混淆是否有独立增量；在没有该证据前，不把静态+动态相加或提高参数量当成合理改进已经成立。原054继续作为已评分参照；本轮停止这组分解与小网络扩容。
