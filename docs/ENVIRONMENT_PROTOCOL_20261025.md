# 双验证研究：72次训练与环境子空间对照

最高已测仍0.54，最近两个不同候选均0.53。本轮先检验验证协议与环境适应，不以本地提升承诺平台0.60。

## 实验边界

- 原054及四个历史留房间教师的主干/读出冻结；使用实际ONNX预处理对应的四路证据。条件模块584参数，全局仿射控制8参数；每路最多±10%缩放、±0.1源特征标准差偏移，没有类别偏置或房间ID输入。
- 四目标房间×两种子：源全局/源条件各8次，目标U一致性/条件伪标签各16次，共48次。所有方法每轮有标签抽样完全相同，SHA已核验。
- 目标房间整采集记录哈希分两组，适应/测试互斥，再交换；训练对象不含目标人数标签。源校准NLL只选择50/150步，目标标签在训练完成后才用于评估。
- DG完全没有目标房间的训练/U记录；targetU模型仅见该房间适应组的无标签输入。两协议评估相同的目标记录，按记录配对统计。
- 已知带标签房间也是不同layout；没有同layout两带标签房间。b1仅1记录不能拆适应/测试；unknown不合并为一个房间。历史代理不使用unknown源记录，真实全量054仍由全部48条训练。
- 开发房间已反复使用，条件伪标签方案与一致性方案若相同可能因为可信样本不足；不把一致性当准确率。

## 本轮总决策

共完成48次小模块训练、24次图分支训练及两种维数的子空间对照。图分支通过门槛的协议：无。
门槛为整体至少+2个百分点、至少两房间受益、任何房间退步不超过2个百分点、按记录提升区间下界大于0；目标U还需明确优于匹配的源训练图模型。
研究用目标U来自留出房间的标签遮蔽记录，用来模拟目标环境可见；没有把官方150条U用于这72次训练。官方数据部分完成ATI全扫描与11条CSI抽查，不能称全量U已用于训练。
关键发现：同一房间的适应组与测试组也可能类别支持不同。e1一折适应组全空房，测试组全1人；强行对齐整体类别分布不成立。
已反复使用的四个开发房间不构成全新盲测。此轮结果只用于淘汰缺乏支持的方向；没有新增平台成绩。
下一步应优先补足其他物理房间的2–4人监督，或先验证能否在不依赖人数分布的条件下估计跨记录背景；现有结果不支持继续放大同一种自训练损失。

全部新权重、输出、计划、划分与审计在D盘上述目录保留；未删除历史最佳模型、未提交平台、未推送Git。

本轮不导出新的推荐ONNX，平台最佳仍为已评分0.54，目标0.60尚未达到。
