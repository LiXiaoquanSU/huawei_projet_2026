# 早期跨通道联合卷积与多视角训练（2026-11-02）

借鉴054的可验证特点：联合处理接收通道，以及排列/时间视角的互补。新网络从零训练，将静态幅度3、动态幅度3、相位6通道对齐输入共享残差CNN；保留4个频率区域的均值/标准差/最大值及13维摘要，五类读出。相位32频组重复到128只是对齐，不恢复频率细节。没有复用全数据037/054权重。

对照：同初始权重及训练预算，仅改变是否对训练批次随机使用6种一致Rx/相位对排列。训练均使用正反时间两视图，NLL+.05时间一致性。推理分别使用原顺序双时间视图与全部6Rx×2时间视图。各自仅源校准均衡NLL选择轮数，同时保留固定末轮。3折×2训练条件，每组12轮，共6次训练72轮、12组读出评估。

## 决策

源选原顺序训练+六视角为408/960，排列训练+六视角383/960；固定12轮对应349/960、454/960，排序反转。排列训练末轮改善不能掩盖源选结果，也不能事后按留出分数挑选轮数。三折中表现不一致，所有源选匹配差值区间包含零，尚未达到0.6。

本轮借鉴了054的早期通道交互与变换融合，但未复制其原权重、特定保护策略或目标校准；不能据本轮低分否定054经验，也不能认为借鉴这些特点就足以复制其平台分数。没有导出提交ONNX，不再以已能运行作为推荐依据。

下一步优先做源侧重复整记录校准/选轮稳定性检查，预先固定规则，再做结构比较。现有单次源校准每类只有少量记录，可能对训练阶段的选择不稳；这是待检验假设，不是已证明的失败原因。新的校准划分本身也不能把已反复使用的开发样本变成盲测。
